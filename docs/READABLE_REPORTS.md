# 正式报告可读性整改

本轮只调整 Markdown、XLSX 的展示与排版。教师正文按测评概况、维度统计、选定群体、教师确认发现组织；未选择群体、没有已确认发现时省略对应章节。XLSX 的技术附录置于末尾；Markdown 的技术附录置于末尾并用折叠块组织，查看器不支持折叠时仍能阅读。

正文人数为整数，平均分、中位数及分值范围默认两位小数，比例两位小数。XLSX 保存数值类型及相应格式，未把它们转换成展示字符串。原始精确值不参与展示回写，完整分布、量表、快照与已确认发现引用可在附录核查。

## 同一份合成报告的前后片段

样例只有合成数据：17 名学生，五个维度，选择算法与数据结构低于 3 分且解题策略不低于 4 分的群体，确认算法分布和组合群体两项发现。整改前基于 main 提交 `a7a6c2812354b2775394879cb019476d77864d5c`。

### 整改前

```markdown
批次：synthetic-report-batch
快照：synthetic-report-snapshot-v1-17
统计规则：edu.statistics.v1

| 维度 | 有效/总数 | 缺失/无效 | 均值（展示；精确） | 中位数（展示；精确） | 最小/最大 |
| --- | ---: | ---: | --- | --- | --- |
| 算法与数据结构 | 17/17 | 0/0 | 2.88；49/17 | 2.75；11/4 | 2/1 / 4/1 |

### synthetic-selected-group
条件：算法与数据结构 &lt; 3 AND 解题策略 &gt;= 4
命中 9/17，比例 52.94%（精确 9/17）；可判定 17，不可判定 0；M/E=9/17。
```

XLSX 原统计页将有效数、缺失数、无效数、均值等逐项纵向展开，同时列出数值、展示值、精确值和状态。仅一个维度就需要七行，均值数值列显示 `2.8824`。

```markdown

### 群体 1

| --- | --- | --- |

## 教师确认发现

### 发现 1：算法与数据结构评分分布（教师已确认）

| 指标 | 结果 | 统计口径 |
```

XLSX 采用相同章节和中文字段，一个维度一行；群体和发现只有存在实际内容时才建立对应工作表。人数格式为 `#,##0`、统计分值为 `0.00`、比例为 `0.00%`。授权匿名评分明细按量表精度显示，内部学生和证据引用集中于技术附录。

## 核查与兼容边界

- 算法维度总分为 `5×2 + 4×2.75 + 4×3 + 4×4 = 49`，均值仍为 `49/17`；正文显示 `2.88`。群体占比仍为 `9/17`，正文显示 `52.94%`。群体算法均值为 `7/3`，正文显示 `2.33`。
- 分布频数、精确均值、统计分母、参与来源记录数、量表上下限与步长、规则及快照引用均保留。技术附录不增加原始文件摘要、文件内容或敏感文本。
- 为零的缺失、无效、不可判定指标从正文省略；非零的影响保留。没有有效评分时统计值保持空值，并解释不按零分计算。零匹配群体保留“没有匹配记录”。
- 教师确认状态仍由既有受控投影决定；未确认、已忽略发现不进入报告。原始评语、依据正文、身份信息、教师自由备注仍按既有白名单过滤。没有以省略“待审核”章节为由开放原文。
- 不修改授权、快照校验、统计规则、数据库和 API 输入输出模型。JSON/ZIP 的结构及生成路径保持兼容。文件仍是静态可编辑快照，不添加公式或自动重算承诺。
- 所有文本继续经过 XLSX 文本单元格防护或 Markdown 转义；下载前后权限、版本校验与文件预算保持有效。

## 回归验证

在 `apps/api` 目录执行仓库规定的 Ruff 与完整 pytest 检查。报告专项可运行：

```powershell
uv run --locked pytest -q tests/reporting tests/edu/test_report_download.py
```

新增 `test_readability.py` 使用合成样例，覆盖正文与附录分离、整数人数、比例分母、文件重开及编辑、半分位舍入边界、非零质量问题、不可判定群体和空发现省略。HTTP 下载回归继续通过真实 FastAPI 路由、临时 SQLite 和合成 Excel 验证四种格式、权限撤销、错误快照、损坏数据、敏感列禁止读取以及导出预算。

合成样例可用 `app.reporting.edu.demo.synthetic_report` 生成；带教师确认的合成输入见 `tests.reporting.test_reviewed.saved_inputs` 与 `attach`。原始教师 Excel 不属于本轮验证输入。
