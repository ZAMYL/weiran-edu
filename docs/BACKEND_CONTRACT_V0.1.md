# 未然 EDU 后端冻结规则 v0.1

状态：用户已确认，作为后端实现基线。确认日期：2026-10-23。

本文件落实本次对话中已确认的四条规则，适用于 `ZAMYL/weiran-edu`。它不是完整 PRD v0.2，不代表前端、分析负责人已共同确认全部需求，也不表示接口或数据库已经实现。完整 PRD 与六类分析算法仍需团队确认。

后续开发先检查仓库已有 API、数据结构和错误处理，优先复用适用实现；公共接口与字段变更须同步前端和 AI 负责人。基础工程现已合并到 main；main 还有离线分析引擎。优先复用健康检查、统一错误响应和分析对象，EDU 数据导入及查询 HTTP 业务 API 尚未实现。

## 1. Excel 解析与质量规则

### 1.1 支持范围与身份识别

- 首版只接受当前《评价.xlsx》的 `.xlsx` 模板，不承诺通用 Excel 自动识别。
- Sheet2 识别“学生信息行＋五条维度评价”的记录块，逐块校验身份、列标题与五维内容。不能只依据固定行偏移机械切块，不能将整个工作表当作一行一个学生。
- 从学生信息单元格拆出 12 位学号和姓名，支持当前模板中的空格、短横线分隔。学号按字符串保留；识别不清时报告错误，不猜测、不按姓名合并。
- 五个稳定维度编码见下表。展示名称、Sheet1 原名称和评价依据原文分别保存，通过明确映射关联；不得使用模糊匹配静默选择标准。

| 内部编码 | 展示名称 | Sheet1 原名称 | 当前模板评价依据锚点 |
| --- | --- | --- | --- |
| `algorithm_data_structure` | 算法与数据结构 | 算法与数据结构掌握程度 | `Sheet1!L3` |
| `code_implementation` | 代码实现能力 | 代码实现能力与工程素养 | `Sheet1!L8` |
| `problem_modeling` | 问题建模能力 | 问题分析与建模能力 | `Sheet1!L12` |
| `efficiency_awareness` | 效率意识 | 时间与空间效率意识 | `Sheet1!L16` |
| `solution_strategy` | 解题策略 | 解题策略与应变能力 | `Sheet1!L20` |

依据锚点属于当前模板适配规则。读取合并单元格的有效原文，并保存实际合并区域。模板结构或映射发生变化时，报告模板错误并升级适配器版本，不能悄悄沿用旧位置。

### 1.2 评分与原始证据

- 评分接受闭区间 `[1, 5]` 内、最多两位小数的有限数值。半分合法，零分、越界、缺失或无法解析的值不合法。
- 使用十进制解析与定点表示，禁止自动取整、四舍五入、截断、补分或把缺失当作零。
- 原始身份字符串、原始评分、原始评语、评价依据原文与规范化值分别保留。真实身份信息仅进入受控存储，不通过普通页面接口返回。
- 每条评分及依据保留上传文件哈希、工作表名、行号、相关单元格或区域，并在入库后关联批次及稳定证据 ID。
- 评语不得因清洗丢失。用于匹配、展示的衍生文本不能覆盖原文。
- 当前模板适配器不计算 Excel 公式。评分或必要依据含公式且无法可靠取得原值时，报告格式错误，要求提供固定值文件，不将缓存当作重新计算结果。

### 1.3 错误与警告

| 级别 | 情况 | 行为 |
| --- | --- | --- |
| 阻止入库 | 学号无法识别、同批学号重复 | 返回错误位置，不合并、不覆盖 |
| 阻止入库 | 维度缺失、重复或未知 | 返回所在记录块及单元格，不丢弃记录 |
| 阻止入库 | 评分缺失、非法或超出精度 | 返回错误位置，不修改原分 |
| 阻止入库 | 评价依据缺失或无法对应 | 返回 Sheet1 位置或缺失映射 |
| 阻止入库 | 记录块结构异常、损坏文件、错误模板 | 返回可理解的错误，不产生正式批次 |
| 警告 | 空评语 | 预览提示，允许教师确认 |
| 警告 | 不同学生使用重复评语 | 列为待复核线索，不自动判断评分错误 |

- 错误和警告包含级别、错误码、原因、工作表、行号和可定位时的单元格；不在错误消息或日志中回显真实身份和原始评语。
- 存在任一阻止入库错误时，整份文件不能确认入库；首版不支持跳过错误行后部分导入。
- 测评日期、课程未知时为 `null`。不推断日期、不虚构课程。
- 学生数、评分数均从本次文件重新计算。当前样本的核对数量不是导入条件，UI 和解析器不得写死人数。

## 2. 独立数据库与批次规则

### 2.1 存储与身份

- EDU 使用独立 `edu.sqlite3`、独立配置及迁移记录，不读写旧决策沙盘的业务数据库。
- 原始文件、身份映射、暂存内容和真实数据库保存在仓库外受控位置。独立数据库不意味着数据已经加密或自动具备权限隔离。
- 每批测评是数据库记录，不按批次创建新的数据库文件。
- 学生以“数据来源范围＋学号”匹配，使用稳定内部 ID。来源范围是服务端受控的试点或学校数据命名空间，不能由普通请求任意伪造。
- 姓名只用于核对，不作为唯一键。对外提供稳定匿名 ID；匿名 ID 不能由真实学号直接拼接。
- 批次至少保存批次 ID、所属教师、来源范围、测评日期、课程、评价标准版本、解析器版本、文件哈希和规范化内容摘要。

### 2.2 预览与确认

- 上传预览只创建暂存导入记录，不创建正式测评批次。
- 暂存状态限定为：`preview_ready`（可确认）、`invalid`（有阻止入库错误）、`committed`（已入库）、`expired`（已过期）。
- 可确认预览有效期为创建后 24 小时。到期未确认的预览不能再确认，需重新上传。正式批次不因预览到期而失效。
- 确认操作重新核对教师权限、来源范围、状态、有效期及预览对应的校验结果、解析器版本和评价依据版本；不能将预览后被改变的数据直接入库。
- 批次、学生关联、评分、评价依据和证据关联在同一个数据库事务内写入。任一步骤失败，正式数据全部回滚，不能留下半批测评。
- 同一预览重复确认返回同一个批次。并发确认由数据库约束和事务保证，不能只靠前端禁用按钮或先查后写。
- 已入库记录重试确认时，先检查权限，再返回原批次，不因暂存内容已清理而重新导入。

### 2.3 重复与修正版

- 重复判断限定在同一数据来源范围内，并先执行资源访问检查，不能向无权限教师泄露已有批次信息。
- 文件字节哈希相同，返回已有可访问批次，不生成新测评。
- 文件不同但规范化内容相同，也按重复导入处理。内容摘要包含学号、维度编码及评分、原始评语和评价依据；采用确定性序列化、稳定排序，并记录摘要算法版本，忽略行排序和 Excel 样式。
- 原始评语或评价依据改变不能因文本清洗被当作完全相同。仅换文件名、样式或行排序不能绕过防重。
- 不通过修改课程或日期把同一内容悄悄记作新测评；返回已有批次，不静默改写其元数据。
- 修改已入库评分或评语，导入修正版批次，关联旧批次、保留历史。首版不提供直接修改评分的 API，不物理覆盖旧证据。
- 跨批次仅建立学生身份关联，不自动判定测评标准或难度可比，不据此生成成长结论。

## 3. 数据接口与统计口径规则

### 3.1 接口范围

统一前缀 `/api/v1/edu`，JSON 字段使用 `snake_case`，公共请求与响应使用明确的数据类型。以下为已确认的接口设计，不代表已经上线。

| HTTP 方法 | 相对路径 | 用途 |
| --- | --- | --- |
| `POST` | `/imports/preview` | 上传文件，返回预览、质量报告和 `import_id` |
| `POST` | `/imports/{import_id}/commit` | 确认入库，返回 `batch_id` |
| `GET` | `/batches` | 查询当前教师可访问批次 |
| `GET` | `/batches/{batch_id}/statistics` | 查询五维统计 |
| `POST` | `/batches/{batch_id}/groups/query` | 筛选匿名学生群体 |
| `GET` | `/batches/{batch_id}/students/{student_id}/evidence` | 查询获授权评分、评语及来源 |
| `GET` | `/batches/{batch_id}/rubric` | 查询该批次评价依据 |

路径中的 `student_id` 是对外匿名学生 ID，不是真实学号。预览和证据响应同样执行脱敏。

### 3.2 筛选与比例

- 筛选支持 1～2 个维度条件，条件之间固定为 AND；仅接受 `lt`、`lte`、`eq`、`gte`、`gt`，不接受任意表达式或 SQL。
- 筛选条件必须引用当前批次存在的稳定维度编码，并通过服务端数值校验。
- 返回 `matched_count`、`total_count`、`ratio`。`total_count` 为当前批次全部有效学生数，`ratio = matched_count / total_count`，数值范围为 0～1。
- 正式批次必须有至少一名完整有效学生。无数据页面返回明确无数据状态，不构造虚假的零分统计或执行零分母除法。
- 人数和匿名名单使用同一份筛选规则和同一批次数据；分页仅影响返回名单长度，不影响总人数和比例。
- 返回明确的 `batch_id`、执行条件及 `rule_version`。批次切换时不能继续使用上一批次的证据列表或统计。
- 评分证据拥有稳定 `evidence_id`，关联批次、匿名学生、维度、评分、获授权评语与来源。不能使用分页序号或模型生成文本充当证据 ID。

### 3.3 错误与分析边界

- 统一错误对象包含 `code`、`message`、`request_id`。导入错误附带质量问题列表、工作表和定位信息，不返回异常栈。
- 无身份、无资源权限、非法输入、预览过期、模板错误、确认冲突、数据库错误均有明确状态，不能以成功响应掩盖失败。
- 六类分析的具体公式、四分位数算法、缺失值口径、Spearman 边界、主题词典、洞察阈值及黄金样例，仍由后端与分析负责人共同冻结。
- 本次冻结接口职责、上述公共字段与行为。完整请求/响应 DTO、错误码明细及 OpenAPI 样例应在接口实现前与前端、AI 负责人对齐；不得声称完整 JSON 契约已经共同确认。

## 4. 教师权限、脱敏与 AI 访问规则

- 所有 EDU API 由服务端验证教师身份，只允许访问教师拥有或明确获授权的批次。游客会话没有真实 EDU 数据访问权。
- 上传、预览、确认、批次列表、统计、筛选、评价依据及证据读取逐项检查资源归属。知道 ID、来自某个前端页面或隐藏了按钮，都不能替代授权。
- 普通页面响应不返回真实学号、姓名或原始身份字符串。身份映射与原始文件独立受控；不进入日志、截图、公开演示或提交历史。
- 原始评语也可能含身份信息。页面展示和 AI 输入均检查并遮蔽此类信息，原文仅保存在受控存储中。尚不能完成必要脱敏时，不开放真实数据演示或外发。
- 首版公开演示仅使用合成数据或经审核的脱敏副本，不开放真实批次自由筛选。小群体信息披露也应纳入演示审核。
- AI 只能使用预定义的统计、筛选、证据与评价依据读取工具，继承当前教师权限并绑定明确批次；不能任意查询数据库或跨批次取证。
- 上传、预览和入库不自动调用外部模型。由教师主动触发分析，默认只发送必要汇总统计与评价依据。
- 个人评分、评语等证据外发前另行确认授权。触发分析按钮不能自动解释为个人数据外发授权；缺少授权时仍可使用获授权的汇总数据。
- 人数、比例和分数由确定性程序提供。模型解释和假设不能回写成评分事实。
- 外部模型的密钥只在服务端配置，不进入客户端或仓库。

## 5. 实施顺序与验收

### 实施顺序

1. 检查已有实现，确认完整 DTO、版本与合成验收样例。
2. 完成固定模板解析、匿名预览和行级质量报告。
3. 完成独立数据库、迁移、暂存、事务确认和重复导入控制。
4. 完成教师权限、批次查询、群体筛选和证据下钻，联调前端。
5. 取得分析算法口径后接入统计与 AI 工具；个人数据外发另行授权。

解析服务可以先用合成数据独立验证，真实数据接口在鉴权与脱敏具备后才开放。

### 必须覆盖的验收场景

- 正常文件完整对应学生、五维评分、评语、评价依据及来源，统计数量动态产生。
- 重复学号、缺维度、重复维度、缺分、越界、超出精度、错误模板、损坏文件返回准确问题位置，不能部分入库。
- 空评语和重复评语显示警告，不自动修改评分或丢弃记录。
- 半分和两位小数无损保存；非法精度不能静默四舍五入。
- 重传同一文件、只改样式、改行排序及并发确认均不产生重复测评。
- 确认中途数据库失败时，不残留正式批次或部分评分；重试不会重复写入。
- 无权限教师、游客、伪造来源范围及跨批次证据请求无法获得真实数据。
- 预览过期不能入库；已成功确认的请求重试仍返回原批次。
- 筛选人数与所有分页证据合计一致，条件边界正确，比例分母固定。
- 修正版保留旧批次、旧证据和版本关系。
- 未触发分析或未获个人数据外发授权时，不向外部模型发送个人记录。

上传大小、解压后体积与工作表行数上限，原始文件与身份映射保留期限，教师认证实现和完整错误码表属于实现前仍需明确的配置或设计；本文件不虚构这些事项已经完成。
