# V1冻结范围

已在真实本机服务验收的功能：

- 正式V1双Sheet、五维Excel上传、分步预览、质量报告、警告确认、批次入库。
- 全局统计、合法小数、AND筛选、四类正式发现、完整图表、原群体与评分来源回查。
- 发现进入画像探索；按快照/原条件回放，刷新重新鉴权，分页不改变人数。
- 保存最多三项显式选择的正式发现；旧统计候选兼容；三态核验与版本控制。
- 已确认发现的XLSX和Markdown导出，下载前重新核验权限/快照/版本。
- 只读、撤权、过期凭证、冲突和正常零发现；390px视口。

未上线/不得声称已完成：

- 不支持任意比赛和课堂作业格式；正式输入仍是上述五维Excel。
- Canonical逐题ZIP/HTML、动态工具和远程Qwen仅处于隔离合成实验阶段。
- 正式教师界面没有自主Qwen Agent；没有正式教师资料的真实Qwen质量/成本结论。
- LangGraph未启用；发现质量修复与独立oracle评测的待审分支没有混入本次冻结。
- 不推断学校、班级、课程、比赛名称、测评日期；不把评分差异称为教学效果或因果。
- 无公网部署、学校SSO、付费模型自动调用、自动生成无证据能力评价。

保留「学情洞察、画像探索、测评数据」模块与当前视觉，没有第三套前端。
