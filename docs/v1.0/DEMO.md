## 技术说明（备用30—45秒，不把实验伪装成正式页面）

1. 确定性内核按有效评分、明确分母与互斥成员计算统计、关联、群体差异等，
   来源与快照由程序核验，教师可回查指标对应的实际评分。
2. 受控Agent是独立实验入口：每轮规划器选择一个白名单工具，程序执行、校验事实，再决定继续或停止。
   运行最多6次模型请求、5次工具尝试；只允许选择本轮已核验、合格事实。
3. 可在后台用 `python -m app.ai.edu.discovery.demo` 展示真实离线Fake/Mock Trace，
   对比53人差异与17人同分的不同路径。Fake/Mock验证机制，不能证明真实模型自主发现质量。
4. 正式教师页面当前使用本地确定性发现。真实Qwen尚未进行正式教师数据测试，
   逐题ZIP/HTML是合成原型；LangGraph不作为V1默认框架。
