# 分析准备度与可选择的资料补全（未来设计）

状态：任务 #8，初次交付的验证基线为 main `23f876d`（从 `12dd7f9` 开始开发）。五维是推荐 Profile，项目集合来自实际测评方案。[通用模型](CANONICAL_ASSESSMENT_MODEL.md) 定义数据实体；本文不改变现有教师五步流程、V1 解析器、正式 API、数据库或任务 #7 / Issue #18。

产品展示修订：依据 [PR #23 负责人反馈](https://github.com/ZAMYL/weiran-edu/pull/23#issuecomment-6392744109)，采用“分析优先、资料建议次之”。下面的界面契约和文案均为未来体验目标，没有实现网页组件；当前 V1 固定模板仍不能直接上传三维、八维、自定义维度或逐题成绩。本次不改变原型字段、分析规则、A–H 夹具和归档输出。

## 1. 输入与输出

准备度输入为：受控来源中的方案项目、参与者成员、精确观测、证据/量表关联、批次/方案版本、当前主体权限及本次用途。先授权，再读事实和计算；无资源访问权时整个请求拒绝，不能通过准备度接口探测有无学生/批次。

`AnalysisReadiness` 建议包含以下字段。它是内部设计，不是新的公共成功响应。

| 字段 | 语义 |
| --- | --- |
| dataset_id / dataset_version | 数据集合及不可变版本 |
| batch_id / batch_version / rule_version / purpose | 分析范围、准备度规则版本、本次用途；生产接入还须绑定 snapshot_id 和实时权限版本 |
| recognized_items | 实际全部项目的 ID、原名、类型、原量表、确认的 Profile 映射，以及质量计数和证据可用状态；不补推荐项目 |
| available_fields | 当前用途下存在且可用的评分/评语/答卷/标准字段；不表示每条记录都完整 |
| missing_fields | 缺失或当前不可用的字段；须联查 absent/withheld/unconfirmed_source，不能统一说文件没有资料 |
| quality_issues | 单元格缺失、非法、范围未知、证据缺失/未确认/未授权及影响范围；不返回原文或凭据 |
| available_analyses | 全范围满足本能力必要条件；没有执行分析、没有生成结论 |
| partially_available_analyses | 有明确有效子集；列 eligible_count、完整 denominator、排除原因和项目/人群范围 |
| unavailable_analyses | 当前无合格记录，或缺少能力的全局前提；不返回伪造的零异常/零进步 |
| suggested_resources | 内部可选建议集合，包含下表五项解释及影响范围；不是教师界面的必显清单，默认折叠 |
| limitations | 量表、范围、授权、模型与未实现能力的边界 |

字段存在性、质量和用途授权独立记录。原型 `recognized_items[].evidence_availability` 区分 `absent / available / withheld / unconfirmed_source`，`criteria_availability` 同理。`available_fields` 与 `missing_fields` 可以同时包含同一项目字段，表示部分记录有、部分记录缺，不能当作全体覆盖。具体缺失/非法数来自逐记录检查，分母不是有分人数，也不是页面条数。

这些字段不应直接全量渲染成教师端“缺失资料”或错误列表。尤其 `quality_issues` 目前还收纳范围未知、来源和用途授权状态，展示时须按第 4 节区分真实质量问题、资料可选增益和访问限制，不能仅因落在该字段就显示红色错误。

## 2. 能力判定规则

| 能力 | 必要前提 | 缺资料时仍能做什么 |
| --- | --- | --- |
| 项目评分统计 | 至少一条可信、当前用途可用的数值评分；按项目/原量表分别统计，非法值排除并报告 | 不要求评语/答卷；量表未知只可描述原始数值并标 range_unknown，不能解释等级或跨量表比较 |
| 项目组合探索 | 至少两个实际数值项目；按同一参与者取各项目有效授权记录的交集，并报告配对数和排除数 | 可做原始分值联合分布；各轴保留各自量表，不把分差、均值或权重直接相加。相关需另校验样本数、常量输入及方法适用性，原型不宣称可用相关结论 |
| 评价复核准备 | 单条记录具有可信有效评分、适用版本的标准、对应评语和原始答卷，且均获本用途授权 | 仅有评分可继续统计；仅有评分+评语可提供受限文字线索，但不能宣称已核查答题表现或评分正确。原型的 evaluation_review 专指更深入的人工复核资料准备度 |
| 跨测评变化描述 | 至少两个真实测评时点、可靠匿名匹配、项目/量表/标准可比、任务难度和条件说明、授权和教师确认的比较范围 | 缺任何一项就不能自动宣称能力进步。修订版不是成长；即使可比也只能描述条件内变化，不证明教学因果。原型始终不执行此能力 |

准备度可随输入改变：补上已有学生的缺分可增加有效人数；补答卷+标准+评语可增加复核范围；撤销任一必要授权则立即缩小/取消对应能力。与“必须五维”“恰好某人数”或固定 Demo 的预先结果无关。

## 3. 阻断规则及建议的五项解释

每条 `ResourceSuggestion` 必须包含：`missing`（缺什么）、`why`（为什么）、`enables`（补后新增能力）、`can_continue`（当前是否可继续）、`requirement`（可选还是阻断）和 `scope`（阻断哪部分）。`can_continue` 必须结合范围理解，不能表示有错误也可正式入库。

| 情况 / 缺什么 | 为什么 | 补后新增能力 | 不补能否继续 | requirement / 阻断范围 |
| --- | --- | --- | --- | --- |
| 教师主动选择参考 Profile，且想探索方案未定义的某项表现 | 当前方案没有对应测评，不属于上传缺失或质量错误 | 教师自愿另行采集后可分析该项；历史分数不会补造 | 可以，现有三维直接分析 | optional / profile；只在相应探索情境提示，不展示覆盖完成度 |
| 无评语 | 缺少教师文字说明 | 获授权后可进行评语线索检查；深度复核还需标准和答卷 | 可以做评分统计 | optional / review |
| 无原始答卷 | 分数不能证明具体答题过程 | 获授权并补齐其他条件后可进行更深入复核 | 可以做评分统计与组合探索 | optional / review |
| 标准未知/未授权 | 无法核查等级含义、评分依据或适用范围 | 标准解释与受限人工复核 | 可以描述评分，不能编依据 | optional / rubric_based_analysis |
| 无明确范围/单位/步长 | 无法完成量表范围与精度检查 | 可校验范围/精度并限制合法解释 | 可以描述可信数值，标 range_unknown | optional / scale_validation；不允许声称已完成标准核验 |
| 方案已定义项目但缺分 | 部分预期观测不存在 | 真实补录后恢复受影响记录资格 | 其他有效项目/记录可分析，缺失不当零 | quality_blocker / affected_observations；完整分析受阻 |
| 非法数值、越界、超精度 | 无合法数值参与计算 | 教师提供可追溯更正版本后恢复资格 | 只允许明确标注的有效子集准备度；不能称全量成功 | quality_blocker / affected_observations；V1 正式导入整批受阻 |
| 重复 ID、悬空来源、跨学生证据、适用标准冲突 | 事实含义歧义，无法可靠关联 | 来源/引用修正后重新验证 | 不允许部分接受该数据集合 | structural_blocker / dataset；原型抛原因码 |
| 评分存在但未授权/来源未确认 | 当前用途不能使用这条事实 | 取得对应授权/来源确认后恢复能力 | 仅继续其他获授权、可信记录 | authorization_or_source_blocker / affected_observations；不代替教师放开授权 |
| 多次测评无可比性说明 | 时间顺序不等于同一测量口径 | 未来可比范围内描述变化 | 各次可单独分析 | optional / longitudinal_progress；“能力进步”结论当前不可用 |

**五维仅是内部可选参考方案，不作为上传质量评分标准。** 原型结构合法、三项合法评分时 quality_issues 为空；相反，已定义五维的某学生缺一分，recognized_items 仍为五项，缺分明确报告。教师可以不选五维 Profile、不做名称映射，直接使用当前方案；接受资料建议、确认映射均不是开始已有分析的前置步骤。选择“继续”不会消除非法记录、授予权限或让不可用能力变可用。

## 4. 界面展示契约与主次信息优先级（未来体验目标）

老师首次看到合法数据的结果时，应先得到“系统已理解我的数据，可以开始分析”的反馈。实际方案没有定义的项目不提示缺失，教师的三维、八维、自定义项目及逐题成绩不与五维比较完成度。

### 4.1 展示顺序、触发时机和错误边界

| 层级 / 场景 | 展示契约 |
| --- | --- |
| 默认主信息 | 从 `recognized_items` 呈现实际识别的项目、类型和原量表；从 `available_analyses` 呈现当前可做的统计/探索。项目数按输入展示，不附五维分母。只展示当前范围真正支持的能力，不预先生成结果或结论 |
| 主操作 | 存在可用分析、且满足当前导入确认规则时，主 CTA 为“开始探索”，直接进入现有数据分析；不得要求先补资料、选五维或调整维度。确有部分有效子集时，具体分析入口注明参与记录范围与排除原因，不伪装为全量 |
| 可选次信息 | `suggested_resources` 默认折叠在“丰富分析（可选）”，无提醒数字、待办计数、完成标记或自动弹窗。仅在教师主动展开、追问某种当前不能支持的分析，或某条建议能明确增加当前探索价值时，以一条就近轻提示说明增益；不逐项展示完整内部清单 |
| 不重复打扰 | 提示可忽略/收起，忽略后继续当前分析。同一数据版本和探索问题不反复提示；只有教师主动重开或数据/问题变化产生新的相关价值时再呈现，不把忽略记录为“未完成” |
| 真实质量问题 | 方案已定义评分但真实缺分、非数值、越界、超精度、重复或关联冲突时，明确提示实际原因、影响项目/记录、受阻操作和可行处理。仅使用已核验且可展示的定位；未知位置不编单元格。按现有 V1 规则，存在阻止入库问题时不能确认，不以“开始探索”绕过 |
| 资料未提供 | 缺评语、答卷或可选标准只影响依赖它的分析。默认不显示灰色占位卡或醒目“资料缺失”清单；在教师请求相关分析时说明可选补充价值，并保留其他可用分析入口。范围未知仅说明对应校验/解释限制，不误报已知非法值 |
| 资料存在但未授权 | 在教师进入依赖该资料的分析时说明“资料已存在，当前尚未获准用于此分析/展示”，不写成“未上传”，不建议重复上传或默认开通授权；仅受影响能力不可用。展示授权、内部分析授权和外发授权分别判断，未获模型外发授权不使已获授权的内部评分统计报错 |
| 无任何可用评分分析 | 如确无有效评分，展示真实质量原因；如因权限无法读取，展示中性的访问限制及授权入口，不判定文件不合格，也不提供虚假的开始分析按钮。资源整体无权访问时沿用拒绝访问，不透露资料存在性 |

可选提示采用“想了解的内容 → 可自愿补充的资料 → 增加的分析价值 → 当前仍可继续”的自然语言。例如教师主动询问本方案未定义的问题建模表现时：“若想了解问题建模表现，可补充相应测评；当前三项仍可直接分析。”不根据名称猜测维度映射，也不要求教师选择五维参考方案。

**明确不推荐、不得作为教师端设计建议的交互反例：**“3/5 推荐能力维度已覆盖”、五维覆盖百分比、完成度进度条；为方案未定义的维度生成灰色“尚未提供”卡片；首页显示全部可选资料的醒目缺失清单；必须“调整评价维度”或“补齐五维”才能继续；将八维描述为“超标”、三维描述为“不足”；自动把题目转为五维或将自定义名称强制对应五维。这些反例只用于验收排除，均不是待实现界面。

统计中真实的有效记录数、配对数和完整分母仍须保留，它们用于解释某项分析范围，不是上传相对五维的质量分或完成度。

### 4.2 四种教师界面内容预览

以下均为完全合成的未来文案预览，不是正式 API 响应、现有页面或真实导入验收。前三种要求未来通用导入适配完成；当前 V1 仍只接受原固定五维模板。文案随实际可用能力变化，不写死为所有上传都可分析。

| 合成场景 | 默认主消息及可用分析 | 操作与可选次信息 |
| --- | --- | --- |
| 三维评分、无评语（A） | **已识别 3 项能力评价，可开始统计和群体探索。** “已按你提供的项目保留原始评分，可查看各项分布及组合情况。”不为另外两项推荐维度生成占位 | 主 CTA：**开始探索**。默认仅保留折叠的“丰富分析（可选）”。教师询问评语复核时才提示：“若想结合教师评语复核评价，可补充对应评语；更深入核查还需适用标准、答卷及授权。当前三项评分仍可直接分析。” |
| 八维自定义（C） | **已识别 8 项自定义评价，可开始统计和组合探索。** “已保留全部项目及各自的评分规则，你可以按原项目名称查看。”不进行五维完成度比较 | 主 CTA：**开始探索**。不弹出映射确认、不要求选五维。教师主动询问跨量表汇总时才提示：“当前可分别查看各项目；若需要汇总，请先确认可比范围和汇总口径，原始评分会继续保留。”不暗示确认后已有汇总实现 |
| 十三道编程题成绩（D） | **已识别 13 道题目得分，可开始逐题统计和组合探索。** “已保留每题得分及原量表，可查看各题分布与同一参与者的联合表现。”不输出虚构的五维能力 | 主 CTA：**开始探索**。教师主动询问答题过程核查时才提示：“若想进一步核查解题过程，可补充对应答卷和适用评分标准；获得所需资料与授权后才可进行相关复核，当前题目得分仍可分析。” |
| 评分实际非法（独立合成例：方案定义五项，1 条算法评分为 6，原量表为 1–5） | **已识别 5 项评价，发现 1 条评分超出量表范围。** “算法与数据结构有 1 条评分不符合原量表 1–5，请核对原评分，修正后重新提交；系统不会自动改分。”这是实际评分问题，与五维推荐无关 | 主 CTA：**查看评分问题**；有真实定位则定位，否则展示问题列表。明确“本次文件暂不能确认导入”，不显示“开始探索”绕过 V1 阻断。原型可计算有效子集准备度，不表示正式系统支持部分入库或已有相应页面 |

“未提供”和“未授权”的相关分析提示分别为：“若想核查答题过程，可选择补充对应答卷；当前评分分析可继续。”以及“答卷资料已存在，但当前尚未获准用于此次复核；获得相应用途授权后可进一步核查，当前已获授权的评分分析可继续。”只在拥有相应元数据访问权时使用后一文案，不把展示授权解释为外发授权。

## 5. 计算顺序与安全边界

1. 在可信服务端校验主体、来源和批次权限，再在一致快照内读取事实；每次请求重验撤销和用途。原型没有真实权限服务，授权只由合成夹具声明，不能用于保护真实数据。
2. 校验实体唯一性、方案项目集合、参与者成员、证据归属及标准适用范围。结构问题明确失败，不能静默丢行或选择有利来源。
3. 按当前用途检查评分证据；被扣留时不查看数值、不给出该值的质量细节。对可用评分精确校验；没有定义的项目不生成缺失行，有定义但缺观测才记 missing。
4. 分项目计算合格记录集合；组合用交集，复核逐记录检查所需资料。没有合法分母时为 unavailable，而不是假 0 分或假 0 异常。原型只输出计数/资格，不重复实现正式统计引擎。
5. 内部可以保留 Profile 参考建议；教师未选参考方案时不进行教师端比较。只有教师主动选择参考方案且提出相关探索需求时，才基于**确认映射**提示具体增益，不渲染覆盖率/完成度或方案外“缺失项目”。未确认名称不由 AI 猜测，追加项目不会删除原项目。
6. 输出具体建议、限制、版本。缓存必须随数据/方案/规则/权限和用途改变而失效；能力声明和匿名 ID 都不是读取授权。真实接入还须成本上限、分页与小群体披露控制，不能把本原型直接注册成 HTTP。

## 6. 合成 A–H 与实际输出

[synthetic.py](canonical_assessment/synthetic.py) 构造所有事实，不读学生文件。以下为可执行结果的精简选段；完整输出由原型生成并保存于 [synthetic_outputs.json](canonical_assessment/synthetic_outputs.json)。准备度状态不是分析执行结果。这些是内部验证输出，不是教师端展示稿；内部 `profile` 建议及 `missing` 字段保留供规则验证，不能据此要求 UI 全量显示。教师端遵循第 4 节的优先级和触发时机。

| 场景 | 合成输入 | 应观察到的准备度 |
| --- | --- | --- |

## 7. 已实现、原型验证和后续设计

V1 已实现固定模板解析、五维精确统计、群体筛选、来源回查及试点授权；评语/标准原文仍 withheld。负责人反馈时 [PR #19](https://github.com/ZAMYL/weiran-edu/pull/19) 已合并，正式五维洞察接口由该工作交付；本轮不修改或耦合其代码。动态项目的准备度、资料依赖和可选建议只在此次合成原型验证，第 4 节的展示契约与文案尚未在前端实现。

通用持久化、通用文件识别、非数值资料处理、真实用途授权、动态分析执行、比较等价性验证与前端接入均为未来工作；须经独立 Issue、契约评审和迁移/隐私验收。本轮无真实学生资料、无真实 Qwen、无部署，不能将 available 等同于正式系统能力已上线。
