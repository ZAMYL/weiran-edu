## 规划数据流

经授权的测评 Excel → 清洗、规范化与质量校验 → 规则化分析及评语主题分类 → 带原始评分和评语依据的分析结果 → 教师查看与 AI 教学解释。

- 统计、评分和主题分类规则由确定性程序执行；具体公式、阈值和六类分析定义等待 PRD 确认。
- AI 教学解释基于可追溯的分析结果及经授权的最小必要信息，不替代原始评分与评语证据。
- SQLite 为计划中的存储方案；本次没有建立任何表、迁移或数据库文件。
- 数据基础按用户确认的后端规则从首版支持多批次，批次与学生关联、预览后确认、重复导入和修正版保留历史见设计草案；成长分析的可比性与具体算法仍待确认。本次不实施数据库 Schema。

## 开发前的共同决策

确认 PRD 后，再定义 Excel 字段、质量校验与失败状态、证据定位方式、API 输入输出、数据库结构、数据访问权限、脱敏及保留策略。外部模型的数据使用边界须获得明确授权。

本仓库不保存原始学生数据、真实数据库或凭据。当前已有 GET /api/v1/health、通用错误处理、请求编号、配置读取、独立 CI 和离线分析引擎；不包含认证实现、业务接口或部署。
