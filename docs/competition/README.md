# 未然 EDU｜传智杯展示资料

> **V1.3.1 展示候选 · 2026-11-17**  
> 项目方向：面向高校编程教学与程序设计竞赛的 AI 辅助能力画像与可信分析平台。

[返回仓库首页](../../README.md) · [统一集成 PR #100](https://github.com/ZAMYL/weiran-edu/pull/100)

## 一句话介绍

将测评数据导入、五维评分分析、群体差异发现、受控 AI 调查、依据核验和教师报告连接成完整的教学分析工作流。

## 五分钟演示路线

| 时间 | 画面 | 讲解重点 |
|---|---|---|
| 00:00–00:20 | 产品首页与高校编程测评场景 | 问题和定位 |
| 00:20–01:00 | 导入 105 人真实竞赛脱敏评价表 | 数据来源、匿名化、导入检查 |
| 01:00–01:45 | 五维分析与群体差异 | 有意义的实际统计 |
| 01:45–02:40 | AI 调查与画像 | 受控 Agent 与工具支持 |
| 02:40–03:40 | “查看评分依据”与核验 | 追踪人数、维度和原评分 |
| 03:40–04:30 | 教师确认、保存、导出 | 完整业务闭环 |
| 04:30–05:00 | 架构与总结 | 技术创新、使用价值与边界 |

**视频、截图：** 由前端负责人制作；完成脱敏和内容核验后再上传到仓库或发布页面。现在不提供不存在的下载地址。

**演示数据：** 2025 年高校程序设计竞赛的 105 人脱敏评价数据；该工作簿为已形成的评价记录，不是系统直接 OCR 原始答题卡。原始数据文件、个人身份和教师数据库不进入 Git 仓库。演示视频中的人数、统计值与 AI 发现必须来自同一批次。

## 当前展示与发布边界

- [PR #100](https://github.com/ZAMYL/weiran-edu/pull/100) 是赛前集成**候选**，截至本页撰写时仍为 Draft，不代表已合并至 main。
- 仓库已有前后端组合与浏览器 E2E 的报告；正式封版仍需核对准确 SHA、CI、录屏机器的运行和已知缺陷。
- 本机演示链路使用 `http_mock`，**不是实际网络调用 Qwen API**。Qwen 真实路径需要正式路由、独立审批及预算授权，不将模拟输出冒充付费模型结果。
- 评分关系是基于数据的分析线索，不单凭一次评分推断学生性格、因果关系或长期学习成效。
- 当前仅使用受支持的 Excel 模板，不宣称已经支持任意格式的答题卡图片/PDF 自动识别。

## 素材发布约定

1. 录屏原始文件与真实 Excel 先留在团队私有素材目录；发布前检查姓名、学校、学号、账号、Token、本地路径和学生原文。
2. 通过审查后只添加 **少量** 首页截图（1 张工作台全景 + 1 张评分依据细节）和一个完整演示视频。
3. 成片优先保持真实操作；如为讲解设计了示意动画，明确与真实运行画面区分。
4. 不提交 SQLite、日志、原始测评 Excel、密钥、付费审批文件、或未审查的字幕和素材。
