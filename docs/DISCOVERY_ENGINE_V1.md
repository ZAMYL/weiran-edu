# 主动数据发现内核 v0.1.1（探索口径草案）

本模块是内部纯 Python 分析，不是正式 HTTP DTO、权限系统或教学诊断。沿用五维、1–5 分、0.01 精度；通过 prepare_dataset 接入已授权批次，缺失与无效值分别报告，不填零。调用者必须先完成教师权限、快照及证据归属核验。本 PR 不改 Qwen、安全运行模式、页面、数据库、认证、报告或正式接口。

## 有界探索（先确定规则，再计算）

- 相关性：复用既有平均并列秩 Spearman，诊断保留全部 10 对；默认至少 5 个成对有效样本且 |rho| ≥ 0.6 才形成候选。不输出 p 值或因果结论。
- 群体：每维有效评分的最近秩 Q25/Q75（ceil(p*n)，一基）生成 ≤Q25、≥Q75 单条件；然后在不同维度之间组合 AND 双条件。最多 10 个单条件、40 个双条件；默认只尝试前 20 条，硬上限 50。单条件优先，双条件按维度对轮转四种方向，顺序固定、未穷举。先按非条件结果维度逐项检查资格，再按“无方向成员分区＋筛选维度集合＋结果维度”去重；同语义反向比较只保留首条，不合格规则不占位。不同筛选/结果维度的合格事实各自保留。每组至少 5 个有效结果，非筛选维度绝对均值差 ≥0.5 才发现。以上阈值均可配置，是探索参数，不是教学标准。
- 比较对象：目标组与可判定但未命中的余组互斥。M+R+U=N；U 为筛选条件任一维缺失/无效者。M/N 与 M/E（E=N−U）分开。每个结果维度另有各组有效分母。筛选维度的差异是条件定义结果，展示但不参与发现资格及排序效果量。
- 少见组合：对每对有效分数的有符号差 x−y，使用最近秩 Q1/Q3 的 1.5 IQR 围栏；严格越界且离中位数至少 0.5 分、该侧人数/成对有效人数 ≤0.1 才保留。IQR=0 时仍要求最小距离。单个、小群体、群体现象分开标记，全部只是待复核的评分组合，不是能力缺陷。数据质量计数单列，绝不作为个体异常。
- 边界敏感性：显式传入已有观察值边界和其他 AND 条件，复用两次筛选比较 < 与 ≤；默认不自动给所有常数/边界生成卡片。边界不在实际有效评分中或成员无变化时不形成发现。保留精确 Fraction 和实际成员变化；辅助函数仍返回零变化/证据不足诊断。

## 稳健性及排序

相关性和群体差异固定进行 3 次删组检查：按规范排序的学生索引模 3 分组，每次删去一组后重新计算。保持原方向并达到原探索阈值才通过；有效样本不足不视为通过。记录计划/可计算/通过次数。这是确定性的敏感性检查，受排序影响，不是独立验证或置信区间。少见组合另报告越过 3 IQR 外围栏的比例；边界记录精确成员变化比例。这些口径不同，跨类型排序只是启发式。

排序分数 = (4×效果幅度 + 2×min(支持人数/20,1) + 2×稳健性 + 2×完整度)/10；不可计算稳健性贡献为 0 并明确限制。相关幅度=|rho|；均值差/量表跨度；少见组合离中位数距离/(2×跨度)；边界变化人数/E。所有项限制在 [0,1]。同分按类型与内容 ID 排序，最多返回 12 项（可配置，硬上限 50）。分数不是统计置信度，不使用“显著”“可靠”标签。至少 20 人且检查充分才可标记可展示；个体/少见组合始终谨慎。没有合格发现返回空 tuple。

## 输出与接入边界

`discover(dataset, batch_id=..., snapshot_id=..., student_ids=..., policy=..., boundaries=...)` 返回发现、全部相关诊断、逐条搜索审计和质量计数。`compare_groups`、`compare_boundary` 可单独调用。内部模型保留精确 Fraction、逐指标实际来源 RecordRef。ID 含批次、快照、规则版本、评分状态/值、证据元数据和配置的摘要，不依赖固定人数或时间。快照字符串与 ID 都不是权限凭证。

`present(discovery)` 仅投影程序生成标题/事实、汇总数值（精确分子分母与展示值）、图表、条件、状态、排序口径和限制。只给出不含学生标识的受控查询键，不暴露内部定位、姓名、学号、评语或逐人评分。学生数分母单列，不能把 Fraction 的分母当作人数。小样本不可公开发布；本模块没有公开分享授权。

后端需以授权的批次/快照/群体重建或保管结果，再解析 `(discovery_id, metric_key)`，调用 `sources` 取得真实参与者。再次检查当前权限、快照和评分证据归属后才能返回匿名学生/evidence_id。这里仅匹配同来源、同维度的评分引用；不读取任何评语或 withheld 原文，不伪造正式 evidence_id。整体群体成员资格不能代替具体指标来源。

前端将来使用：id/type、batch_id/snapshot_id、title/summary、status、metrics/charts、conditions、ranking、limitations、controlled_queries、public_display_allowed=false。群体图应同时显示目标/余组各维有效分母、缺失/无效数；条件维度须显示“条件定义”。当前没有接线 API 或页面。

下一 PR 可在既有受控工具执行层加入发现查询，由 Qwen 选择后续调查；本 PR 不修改规划器，不向模型传递真实数据。仍需独立评测证明 Agent 的增量价值。

## 限制与待确认

探索存在多重比较与选择偏差；没有校正检验、因果证明、教学效果证明、跨批次成长推断或经过教师校准的阈值。尾部分组及差值围栏仅是易解释启发式，量表不同维度的差不能视为等价能力差。删组结果取决于规范 ID 排序，不是随机抽样。小样本、缺失非随机、评分偏差可能改变结论。需要教师确认阈值、群体最小展示人数和业务授权规则，不能直接用于改分或给学生贴标签。

合成复现：`uv run --project apps/api --locked python scripts/edu_discovery_demo.py`。53 人 seed=42 的已知边界例：算法≤2.75 AND 策略≥4 为 5 人，改为算法<2.75 为 4 人；这些人数仅为测试预期。

围栏方法参考 [NIST 箱线图说明](https://itl.nist.gov/div898/handbook/eda/section3/boxplot.htm)。本实现另行明确采用最近秩分位数，并增加最小差值和稀少比例约束；这些属于本项目可配置探索规则，不能据此声称统计显著。

非空组的指标来源查询键：`target_members`/`remainder_members` 是筛选归属；`target.IMPLEMENTATION` 等是该维有效评分参与者。相关性使用 `paired_scores`；少见组合分别使用 `rare_members` 与 `pair_reference`（不能混用）；边界使用 `strict_members`/`inclusive_members`/`added_members`。空源返回空集合，不拿同批其他记录补齐。引用的来源、维度以及实际参与者都必须匹配。评分证据链接缺失时返回空链接，记录查询引用仍保留，调用方不能声称原始证据已齐全。

所有配置随发现投影返回 `parameters`；整体返回 `qualified_count`，截断后的 `findings` 数可能更少。搜索审计仅反映实际预算内尝试，不代表所有群体均已搜索。一个规则可以产生多个合格结果维度的卡片，分别计算各自的稳健性与排序；GroupComparison.outcome_dimension 与 metrics.outcome_dimension 明确卡片主结果维度。standalone compare_groups 默认该字段为 None，仍返回完整五维对照。排序相同按类型/内容ID稳定处理。

## PR #41 R1 修复口径

规则版本 `edu-discovery-0.1.1-draft`。不再先登记整个分区，也不再只取幅度最大的一个结果维度：先逐项筛掉条件维度、样本不足和差异未达门槛者，只有真正生成卡片后才登记该结果语义。互补方向的两组视为同一比较；筛选维度集合或结果维度不同则不是相同事实。相同筛选维度/结果维度及同一分区，即使规则写法或方向不同，仅保留按既有搜索顺序遇到的首个合格代表。其实际条件和目标减余组的方向照实保留，不能套用到所有未展示条件。

审查反例20人：前10人算法1/实现2.90，后10人算法5/实现3.10，余维3。算法尾部分组的实现差−0.20不足0.5，不占去重位置；实现≤2.90分组的算法均值1与5、差−4，得到1个合格群体事实（10/10人）。实现≥3.10的同语义反向比较不额外生成卡片。

同分区三维均有4分差时：3个单维筛选集合各有2个非条件结果，加3个双维筛选集合各有1个非条件结果，共9个语义不同的事实；反向与重复AND分区不再增加同一语义卡片。未提高搜索预算：每条规则尝试仍只占1条 search_audit，qualified 表示该规则至少发布1项事实，不等于发布卡片数；duplicate_partition 是沿用的审计标签，现在只表示该规则所有合格结果的语义键都已发布。对每个发布结果复用原3次删组方法，因而多个合格结果的内部计算工作量可增加，但计算次数由搜索预算和每规则最多4个非条件结果维度限制；最终卡片上限仅限制输出，不提前截断计算。

默认最多12项、硬上限50项的最终排序/截断保持不变，qualified_count 记录截断前所有合格事实数。不同维度的真实事实不属于重复，但可能增加候选总数，不能声称默认前12项覆盖全部合格结果。没有修改统计精度、条件规则、来源集合、匿名投影、权限或Qwen模式。
