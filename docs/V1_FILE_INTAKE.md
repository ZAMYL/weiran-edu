# V1 统一上传入口与实现边界

入口为「上传测评文件」。教师不提前指定工作表数量、维度数、测评类型、字段映射或评分模板。本轮仅实现第一优先的后端；页面由林明接入，不修改 apps/web。

## 第一优先：已有格式直接上传

复用 POST `/api/v1/edu/imports/preview`，multipart 必填只有 file；不新增导入 API。现阶段支持的内容仍是已验证的双工作表五维 XLSX，由原解析器检查实际字节，不接受客户端指定模板或修正规则。

```javascript
const form = new FormData();
form.append("file", file);
if (currentScopeId) form.append("data_scope_id", currentScopeId);
// 继续使用现有受控代理/会话，不在构建变量或仓库保存凭证。
```

| 项目 | 契约 |
| --- | --- |
| title 省略 | 取文件 basename，去路径、xlsx 后缀和控制/格式字符，最多100字符；空则“未命名测评” |
| title 显式提供 | 按原规则验证，不覆盖；空字符串仍422 |
| 上传后改名 | 原 PATCH `/imports/{import_id}`，携带 preview_version；确认使用新版本 |
| course / assessment_date | 选填，未知省略；不从上传时间或模型推断 |
| data_scope_id 显式提供 | 当前教学空间，严格核验导入权限；不满足则拒绝，不回退其它范围 |
| data_scope_id 省略 | 普通上传仅自动使用唯一 can_import=1 范围；修订继承本人拥有且可访问的目标批次范围 |
| 无导入权限 | 403 FORBIDDEN，只读成员不能导入 |
| 多范围无上下文 | 409 IMPORT_SCOPE_REQUIRED，页面传已有当前教学空间，不随意选第一个或创建范围 |

旧显式字段和 ImportView 响应兼容，未知/重复字段仍拒绝。默认 title 是该批次获授权读者可读的正式元数据，并非匿名字段；原文件名和路径不单独持久化，不进入证据或错误。修改名称不改变分数/原字节/摘要，重复导入不覆盖已有批次名称。

交接补丁保留原响应字段，增量返回ImportView.recognized_items和CommitResult.snapshot_id。前端显示后端识别项目及全量计数，确认后直接进入返回批次的诊断；重复打开已有批次，不再手动选择。见[林明接入契约](IMPORT_FRONTEND_HANDOFF.md)和实际合成响应。

## 结果及缺失项

- 支持且有效：201、preview_ready；展示真实预览与质量报告，经原有警告确认及 commit 才生成正式批次。
- 可解析但有必要信息缺口或非法评分：201、invalid，原固定问题码及单元格定位提示修改文件后重传；不提供在线映射/规则补填、不补零或丢弃错误学生。空评语仍按原 warning 确认。
- 当前结构不支持：解析器 UNSUPPORTED_SHEETS 映射422 IMPORT_FORMAT_UNSUPPORTED，固定中文“当前暂不支持此文件结构，未创建测评批次”；不返回假预览/批次。仅表达现有判定边界，不表示实现了任意结构识别。
- 容器不支持：zip/html/xls 等仍415。伪装成xlsx仍检查实际内容。
- 保留损坏/宏/公式/外链/打印设置/资源限制检查；503繁忙或超时不伪装为成功或格式不支持。

## 后续顺序

第二优先识别实际动态项目，保留题目、指标和量表区别，复用 Canonical 与 #56 的精确值、来源和逐用途状态。当前正式 SQLite、快照校验和 Reader 仍固定五维，需配套评审最小存储/读取扩展；本轮八维/逐题 Excel 仍不支持正式入库，不要求教师将其改成五维。

第三优先根据明确协议和合成/脱敏样例，逐个增加经过完整解析、验证、预览、提交及来源回归的适配器，不承诺任意 Excel。十三题不转五维。#56 ZIP/XHTML 仅合成协议，历史 ZIP/HTML 正式验证前不宣称兼容。

缺评语、答卷或标准主要限制对应复核能力，不扩散成新格式的全局必填项；旧V1准入本轮不变。量表未知应明确表达，不默认1–5、不按样本最大值猜满分；数字列不必然是评分列。语义不明不靠AI猜测写库，正式数据不进入Qwen。

## 权限和验收

认证仍在读上传正文前；默认归属在只读事务/线程池核对当前教师、范围和修订拥有者。原 create_import 在解析前后与写事务复核权限；commit 保留预览版本、原字节/内容摘要、解析器版本及当前授权检查。数据库、评分/统计规则不改。

合成真实HTTP验收覆盖：只传文件→隔离解析→预览/质量报告→改名→拒绝旧版本→确认→统计/证据；原字节一致、重复导入、多范围/只读/撤权、修订拥有者、缺分/警告确认、未知布局和客户端映射注入拒绝。后端通过不代表两个页面已完成浏览器验收。
