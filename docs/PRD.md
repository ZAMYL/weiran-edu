# 未然 EDU｜V1.4 当前产品需求概要

**项目定位：AI 时代的编程能力与学习成效诊断平台。**  
**产品口号：让教师看见编程表现背后的能力差异。**

本文件是代码仓库内的简明开发入口，**完整任务、分工、当前授权范围、交付证据以 [GitHub Issue #103](https://github.com/ZAMYL/weiran-edu/issues/103) 为准**。此前“PRD 待补充”和早期冻结规则已不代表当前产品决策。

## 本版真实用户流程

1. 上传编程测评资料：单文件、多文件或 ZIP；上传人自行处理脱敏。系统显示实际文件提供的姓名、学号、时间、代码和评分，不自行改名。
2. 自动识别答卷、题目、参考信息、五维评分资料，智能理解字段关系和可分析内容；数值、代码和测试点由本地确定性解析与统计处理。
3. 沿“算法与数据结构、代码实现能力、问题建模能力、效率意识、解题策略”五个维度展开真实数据分析，发现群体错误模式。
4. 正式网页发起真实 Qwen Agent 调查，模型能够调用已有本地分析/来源查询工具，取得真实结果并形成可核查的发现。
5. 群体总览点击个人，回到当前批次的题目、源代码、测试点、评分和来源；保存并导出报告。

## 开发核心要求

- 新公共上传解除对旧 Sheet1/Sheet2 固定模板的强制依赖，以内容识别 + 可扩展解析适配器处理资料。首批验证已处理好的、相互对应的答题卡 ZIP 与五维评价 Excel，并使用不同人数/结构验证通用性；不把本批人数、题号或文件名写死。
- 复用现有 Next.js、FastAPI、SQLite、五维分析、受控 Agent、证据查询和报告功能；当前正式 Qwen Live 仍需真实端到端验收。
- 原始答题卡和带身份信息的资料仅保存在获得授权的本地环境；公开 GitHub 不上传原件、个体成绩、身份映射和服务端密钥。远程模型使用必要的匿名统计和特征摘要。
- 第一版预留后续代码执行接口；本版交付重点是已有代码与测试记录的理解和分析。
- **成功标准**：同一集成 SHA 下亲自完成真实资料上传、五维及错误模式分析、真实模型工具调查、个人证据下钻、报告保存导出，且一份不同结构/人数的样本能跑通。
