## 联调必须识别的差异

| 历史草案或设计意图 | 当前实际行为 |
| --- | --- |
| 仅健康检查、无迁移或教师授权 | 已有 SQL 迁移和受控业务 API；凭证由管理员 CLI 签发，最长 168 小时，非学校 SSO |
| 全部设计操作均可调用 | 实际另有 `/me`、`/scopes` 和两个正式洞察 POST；需配置数据库，并以运行时 OpenAPI 为准 |
| 部分草案问题码与快照码 | 使用解析器实际问题码；快照冲突是 `409 SNAPSHOT_MISMATCH`，不是草案的 `SNAPSHOT_STALE` |
| GroupResult.items 为较完整的 StudentProfile | 实际为匿名 `student_id/display_label/scores`；快照在结果容器内，详情按需请求学生证据 API |
| 依据正文必返、评语默认可展示 | 初始仍 withheld/null；拥有者审核后 published，返回审核展示文本及独立 review_version；撤回后再次隐藏，不把 withheld 当成没有内容 |
| 预览评分计数可能理解为合法评分数 | `parsed_evaluation_count` 包括检测到的评分行及非法行；完整学生计数与错误/警告计数分别返回 |
| 导入版本/问题名称完全沿用设计示例 | 以服务端返回的版本、稳定行/问题 ID 和运行时 Schema 为准；确认使用最新 preview_version |
| 快照涉及可变的原文审核投影 | 评分、依据及来源事实不可变；修订产生新批次和新快照。审核展示另有版本，不改变评分快照；教师核验结果也单独版本化 |
| 示例学生和内部引用可直接作为正式标识 | 只使用 API 返回的稳定匿名学生及评分证据 ID；内部 RecordRef/EvidenceRef 和预览 ID 不授予正式读取权 |

统计使用完整批次或完整匹配群体，分页不改变分母。矩阵为全批次，群体统计没有矩阵。Decimal 阈值在原始 JSON 上保留精度，数据库整数转 Fraction 后计算；`exact.denominator` 是有理数分母，不是样本数。证据与依据来源可回到原 Excel 的工作表和单元格/范围，但普通 API 不返回原始身份或文件下载。

## 审核与后续验收边界

历史基线通过 675 项，完整性修复后通过 685 项，洞察合并后为 744 项；审核/保存/导出、五个诊断接口与报告核心组合后，本地完整回归 903 项通过；当前提交的云端检查以实际 CI 结果为准。GitHub CI 须以各 PR 当前 head 和最终 main 的实际运行分别核验；这不是前端真实数据联调、真实教师试用或生产验收。

本机已准备联调服务、教师测试凭证和合成 Excel。由前端接入上传 → 预览/质量报告 → 确认入库 → 批次切换 → 统计/洞察 → 群体筛选 → 学生证据 → 拥有者审核文本 → 保存核验 → 导出。还需验证加载、空群体、withheld/published、权限撤销、快照/版本冲突与请求失败状态。

保留的 [冻结规则](BACKEND_CONTRACT_V0.1.md) 是用户确认的后端行为基线；[API](API_CONTRACT_V0.1.md)、[物理模型](DATA_MODEL_V0.1.md)、[Demo 对齐](FRONTEND_API_ALIGNMENT_V0.1.md)、[引擎交接](BACKEND_ANALYSIS_HANDOFF_V0.1.md) 是对应时期的设计背景。完整 PRD v0.2、真实数据保留、加密/备份、部署保护与外部模型授权仍需单独落实；文本发布须教师人工复核，自动脱敏不代表完全匿名化。
