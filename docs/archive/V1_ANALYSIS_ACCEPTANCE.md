## 核查结论

| 核查点 | 代码现状与处理 |
| --- | --- |
| 固定人数 / 固定结果 | 统计由实际有效分数、筛选由实际条件计算；分析核心未发现 105 人或固定命中数假设，不为“有修复”而改写业务代码 |
| 固定批次 | cohort 显式按 batch_id 和所选 ID 集合取记录；批次相同才去重，不混合不同批次 |
| 洞察事实 / 证据 | 分布引用有效记录、频数引用对应分值、群体引用实际 matches；评价复核引用实际评语/评分；Scope 不能替代实际来源 |
| 正式百分之一分 | 验收显式 ScorePolicy(minimum=1, maximum=5, step=1/100)；核心保留精确 Fraction，非法步长不舍入放行 |
| 演示常量 | apps/web/src/demo、演示测试和前端架构文档中的 105/21 是演示数据；核心不导入它们。固定探索条件不是固定结果 |
| 有意的上限 | AI 默认 max_scope_records=1000、工具输出字节预算、Synthetic Live 固定合成场景均是现有安全边界，不是确定性分析的学生人数要求；保留原样 |
| 无记录 / 无候选 | 缺失不补零；空分母比例 None；零命中不造群体卡；未知批次在核心按空输入处理，批次存在性仍由后端检查 |

未发现本轮需要修改的分析业务硬编码，因此仅新增测试与本文。
源文件真实性、真实权限及教学解释有效性不在这些合成测试的证明范围内。

## 可复用的合成验收

测试输入规模：1、17、53、105、320、2000；这些数只在测试目录，
不是合法名单、系统容量配置或班级人数标准。另用 401 条覆盖所有合法分值。

- tests/analysis/scale_data.py：可指定 size、seed、batch_id 生成五维记录；
  以整数百分之一分声明独立预期值，输入用 Decimal；可加入明确的缺失、
  超范围和非法步长单元格。所有标识、引用和评语完全合成，不读取文件。
- test_generality.py：独立计算均值、中位数、频数和条件命中集合，
  核对 M/N、M/E、来源、边界、子群体、批次隔离和输入顺序；
  全低/全高评分必须改变结果，重复记录拒绝；个体画像与 Spearman 样本数亦覆盖各规模。
- test_scale_review.py：各规模重复评语真实频次、数值冲突与人工核查、
  跨批次同名匿名 ID、无证据不编造、公开投影不带个人详情；
  超出 AI 默认范围时明确拒绝，不通过调大限额来宣称大规模模型链路已通过。

测试同时覆盖 <3 / <=3、2.75、缺失/无效、全缺失、空群体、
同一学生跨批次、重复请求 ID 不重复计数、精确来源集合。
预期值不是另一遍调用被测引擎得到，也不使用固定比例反推人数。
所有验证均离线，默认测试仍禁止外部连接。

在 apps/api 执行：

```text
uv run --locked pytest tests/analysis/test_generality.py tests/analysis/test_scale_review.py -q -ra --durations=6
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked pytest -q -ra
```

真实结果以本 PR 的本次运行和 CI 为准；规模验收不是吞吐量、并发或延迟 SLA。

## 风险与联调清单（不新增需求）

- **林明**：演示导入仍采用 DEMO_STANDARD 整数步长；正式 0.01 分及缺失/无效状态、
  无数据和 0 的区分、分布网格与展示舍入需消费正式结果。
  InsightsPage 仍用 DEFAULT_CONDITIONS 生成演示发现，需联调已有候选；
  105/21 的演示断言不能作为真实批次验收值。页面设计本轮未改动。
- **彭仲楷**：解析结果须使用正式评分策略，提供完整获授权批次/群体，
  不能把分页的一页当全批；按快照和实际参与记录解析证据，校验批次及归属。
  核心隔离缺失/无效不代表正式导入可以跳过质量检查；
  不存在的批次不能只因核心返回空集就被视为合法资源。
- **共同**：公开卡的小样本检查不是身份脱敏或真实教师鉴权；
  candidate_id 需要不可变快照且不是授权令牌。原接口映射差异继续参见
  [ANALYSIS_FRONTEND_HANDOFF.md](ANALYSIS_FRONTEND_HANDOFF.md)。
- **规模**：本次验证纯确定性分析到 2000 条输入，不代表 AI 允许发送 2000 人数据，
  也不代表并发、浏览器大表格或正式导入的容量已验收。
  当前逐分值定位来源会重复遍历记录；应结合本轮耗时与真实链路性能再判断，
  本轮不越界做算法重构、调大 AI 限额或放宽公开门槛。
