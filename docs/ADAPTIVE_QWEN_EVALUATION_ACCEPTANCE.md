## 一条命令

仓库根目录，Python3.12/原 uv.lock：

```powershell
$env:PYTHONUTF8='1'
uv run --project apps/api --locked python scripts/edu_adaptive_acceptance.py --output D:\Temp\acceptance-new.json --markdown D:\Temp\acceptance-new.md
```

输出必须是新文件；退出1表示有覆盖遗漏、失败或安全测试失败，**仍写完整报告**，不是程序没有运行。`not_run` 不是通过。没有 `--execute`、Key、真实教师文件或远程开关。即使环境已有 Key，也只用 `httpx.MockTransport`，不能发付费请求。

## 独立标准答案

- 五维发现数值、资格和语义签名直接复用 #47 `reference()` 与冻结 `oracles.json`，不改 oracle、不改预标目标、不删除 AND 漏检。#58 只返回单结果项，使用明确的字段投影核对，不补造旧 Claim 要求的其他四维统计，不把原型规则版本改写为正式版本。
- 新 `reference.py` 只导入标准库和冻结参考，不导入 app、Kernel、Agent 或 Qwen。逐题固定seed0公式：20人，奇偶题80/20交替；另声明缺分/证据/量表变体。`question_oracles.json` 保留独立汇总、资格目标、来源范围语义和禁止结论；CLI不能自动改答案。
- 手算锚点：Q01均值/中位数50；Q13缺最后5分时有效15、均值60、中位数80；补齐后20人均值50。Q01≤20的10人与其余10人，Q02均值80/20，差60；Q01/Q02 Spearman=-1。3人完整资料Q01均值40、Q02均值60，不能算合格关联。
- 来源核对逐指标的实际参与者、项目、score/row类型、原始字节SHA、定位、内容哈希；五维源引用只在本地以已核验结构等价作桥接。Oracle上下文与运行上下文分别保留，不伪造同一个snapshot。输出来源证明摘要，个人行/原始定位不发送规划器。
- 已发行摘要、调查事实、依据检查、最终选择分开核对。错误摘要即使重新计算了内部hash，也会被独立算术拒绝。未知/错批次/错快照/错误成员证据不能因为ID真实就获得分数。
- 所有已发行参与者集合都做独立累计差分审计，含同轮集合；基数1～4或差分1～4不得发布精确统计。隐私抑制、最终未选择和工具未调查均保留，不悄悄减少目标数。

## 统一采集

`collector.Collected(run, executor, audit)` 复用真实 #58 typed Planner、post_chat 与 Executor。HTTP transcript记录实际模型输入、动态schema、原生消息关联；model_proposals记录实际Mock响应解析，而不是预写期望路线。完整Trace与工具账本分别记录，事实和卡片只能来自本次签发对象。非法最终选择在校验前也计数，不能只看最终空卡片就称模型没有错误。

`grade_native()` 接收受信本地运行对象，并用独立参考核对；它不接受任意JSON冒充真实执行。统计/来源准确率以已发行事实为单位，另保留冻结绑定准确率；无事实时N/A。不是每个已计算事实都能作为最终发现。

`live_record.template.json` 是未来统一真实记录模板：初始 `not_run`，授权、模型、场景/源指纹、价格指纹、预算、Token和账单字段未填。接入真实回调时应填入受信run/executor及原预算快照，再用同一个判分器；不能直接相信模型或上传JSON声称的执行历史。本轮没有真实运行入口。

Mock的返回usage和按该usage计算的价目上界仅放在带 `http_mock` 标签的预算账本。报告 `actual_tokens/actual_cost_cny` 始终null。未来真实调用仍须区分供应商reported usage、按已审价格估算的费用、实际账单对账；没有账单不能伪称实际人民币花费。

## 首次预留与安全验收

#58 的独占journal、请求前fsync、价格/端点/源指纹、6次请求/5次工具、累计披露均未改。仍按最大输入991808+输出800预留 **992608 Token、0.7956064元**；没有证明更小输入上界，因此不会降额。总额度低于该值连首次请求也不发；等于该值完成一次后仍需为下一次完整预留，不能假定后续只花实际短提示的成本。

真实执行依赖 #58 已审价格地域和有效期，当前价格快照2026-11-02失效；这不是该日期前一定不变的账单承诺。首轮真实测试前须重新核验，负责人另行明确场景/指纹、模型、请求数、Token、人民币上限。旧任务的调用授权不复用。

实际安全probe经过原生HTTP Mock执行：未知工具/项目、跨批次参数、伪造最终事实、重复请求、错误JSON、usage缺失、Token/RMB预留不足、单请求上限。安全通过仅表示没有越权发布和错误卡片；非法模型提议仍计数。评分器篡改测试另行标记为评分器测试，不能冒充真实教师鉴权或真实模型红队结果。
