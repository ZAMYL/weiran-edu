# 新增隔离上下文合成审核案例

本材料由本轮未参与 EDU PR #66 策略调试的隔离上下文子代理审核者构造，**不是人类独立批准，也不是完全盲测**。未读取策略、既有案例、冻结 Oracle 或结果，未调用付费模型。已读取指定 canonical model、ItemSpec/_assemble；读取 analysis.py 时整文件输出包含统计 Kernel 实现，超出了最窄的“仅 I/O 契约”范围，因此如实记录此隔离局限。未执行或导入 Kernel/discover/Agent。

## 输入与答案隔离
inputs.json 为运行适配器的唯一输入入口，仅含 case_id/kind/scale/items/rows/seed/生成说明；oracles.json 为封闭预期、来源和资格/拒绝条件。inputs/ 与 answers/ 是逐例审查副本。运行器可向规划器提供输入和产品允许的聚合视图，**不得将 oracles.json、answers/、本说明中的答案、生成脚本或 manifest 作为规划器上下文**。本材料不指定工具调用顺序，不提供参考策略。行索引为 1 起始，列顺序由 items 决定。null 是缺失，不是 0；rubric=null 表示未提供真实评分细则，不能虚构。

## 固定生成与验证
在本目录运行 Python generate_review_cases.py。无随机数、外部数据或项目依赖；三例分别为 40、30、40 人，每例 4 项。生成器只用标准库 Fraction 计算有理数均值、中位数、秩的平方和/交叉乘积；相关系数使用手推解析式并断言独立秩计算所得矩一致。JSON 与 SHA-256 清单可重复生成。原始输入是明确的分块设计，所有非空披露分组、配对来源、评分频数单元均至少 5 人；空来源只表示不存在可用数值，不能形成数值结论。

## 手算依据
- review_corr_scope_20261103：I01 取 1、2、4、5 各10人；I02相同；I04=6-I01；I03在每个I01块内各5人取1和5。四项均值均为3。I01中心秩为 -15、-5、5、15，各重复10次，平方和5000；I03中心秩为正负10各20次，平方和4000，交叉积0。故 I01/I02 rho=1、I01/I03 rho=0、I01/I04 rho=-1。一次关联不能证明未检查维度已调查充分。
- review_missing_support_20261103：Q01为1、3、5各10人；Q02只在前20人有1/3评分，均值2；后10人缺失。Q03为常数3。Q04只前5人有5，其余25人缺失。Q01/Q02配对20人，rho=1；常数输入相关无定义。Q01=1组的Q02均值1，其余组可用10人均值3，差-2；Q04在其余组无可用数值，不能计算均值差。5/30覆盖限制与缺证均应保留，禁止按缺失值推断低分。任何少于5人的后续细分不得披露。
- review_decimal_interaction_20261103：Q01/Q02为(0,0)、(0,10)、(10,0)、(10,10)，各10人；Q03只有首块为2.5，其余为7.5；Q04恒5。Q03均值25/4，中位数15/2。Q01/Q02 rho=0；Q01/Q03及Q02/Q03中心秩平方和4000和3000，交叉积2000，故 rho=1/sqrt(3)。Q01=0的20人Q03均值5，其余20人为7.5；两条件均为0的10人为2.5，其余30人为7.5，差-5。组合描述不能升级成因果交互或显著性结论。

## 来源与局限
answers/ 的每个数值均注明合法 item_id、1起始行索引和证据类型；缺失仅引用 row_declaration，不能当作评分见证。可由评测运行器映射成实际封装后的 witness，而不能把本目录路径或虚构 ID 当实际工具来源。未规定政策排序、显著性、置信度、工具预算终态或真实世界代表性；这些需要实际运行记录和既定政策判断。案例不能证明系统通过，仅提供未参与策略调试者新增的、可手算的封闭输入与答案。目录内测试仅验证这些夹具自身的算术与结构，不是产品测试通过。
