## 2. 预期事实来源和判定

#47已有19个冻结案例与构造说明；新增场景在实施前独立冻结，由literal/Decimal手算或独立参考计算得到，不重写已有失败来迁就Agent。oracle不能调用被测 discover/compare_groups/Spearman 或读取模型回答作为标准答案。文件版本、固定seed、评分工厂摘要与提交SHA进入结果，模型不可读取oracle文件。

预期事实须同时包含：类型、维度、规范条件/结果维度、N/E/U、两组有效样本数或成对n、精确值/浮点容差、实际参与者的本地集合与资格状态。Fraction按精确值比较；rho统一绝对容差1e-12。原始评分不进入远程评测记录或提交的公开输出；工厂纯合成，没有真实教师文件读取入口。

事实签名按上下文、方法/规则版本、维度/条件、结果维度和实际群体语义生成，不按模型文本或 fact_id 判相同。左右维度互换的相关、两组对调后的等价比较需规范化；条件改变但恰好同分区不能抹掉条件/结果维度意义。多轮重复计算同一事实只算一次命中，原始重复次数仍报告。

预定义“有价值”集合是本任务的分析目标，不是所有数学上真实的事实。没有列入该集合的发现不能自动算错误：由独立核算记 verified_extra / irrelevant / unscored，未核算就不得声称已证明真假。真正数值/分母/引用错误单独记 invalid。人工复核这些额外结果使用预先冻结准则并保留记录，不用模型自评。

## 4. 指标及其分母

| 指标 | 计算/分母 | 必须另记 |
| --- | --- | --- |
| 有价值发现覆盖 | 展示的唯一目标事实命中数 / 独立目标事实数 | 目标数0时N/A，不给100%；另报正确空结果/停止 |
| 全部计算覆盖 | 工具得到的合格唯一目标数 / 目标数 | 与模型最终选择覆盖分开，识别“算出但没选” |
| 错误发现 | 最终输出的invalid数；以及模型提出但被拒绝的invalid数 | 不能只因验证器挡住就宣称模型0幻觉；unscored/irrelevant另列 |
| 无依据引用 | 未知/跨run/错batch-snapshot/非参与来源/规则不符的引用尝试数 | 最终泄露/发布数应0；尝试计数不得省略 |
| 重复发现 | 模型选择列表按规范签名重复数 / 原始选择数 | 最终去重数、重复工具请求、缓存命中各自记录 |
| 引用正确率 | 正确绑定尝试数 / 所有引用尝试数 | 分母0为N/A；另报验证器接受的最终引用数 |
| 工具效率 | 唯一有价值且合格事实 / 外层工具尝试；另报计算单元 | 不把缓存命中/失败免记账；工作单元定义随引擎版本冻结 |
| 稳健性/完整度 | 原引擎方法、实际样本和缺失/排除数 | not_computed与0次通过区分；不是统计置信度 |
| 时延 | 总wall、模型网络、计算、验证分别实测 | Fake/Mock时延与真实网络分列，不混成平均 |
| Token和费用 | 每请求实际input/output/cached usage，run求和 | usage缺失null，不用0顶替；Mock标mock，费用未核账则null |
| 安全停止 | 零发现/不足/抑制/预算/超时等逐原因次数 | 模型主动与程序强制停止分开，错误不可伪装成功 |

内部工作单元须可审计：例如 #41 当前默认4次Spearman全对计算（初次+3次删组），每次10对；每个群体尝试有5维×两组统计，每个合格结果维度另有3次×两组删组计算；不能用qualified审计条数代替结果维度数量。可以由版本固定的计数公式与审计结果推导，但应标为 operation_count 而非实测CPU时间；未覆盖的计算不能声称免费或精确总成本。CPU/wall时间另行实测。若需要插桩，限AI适配层，不为计数擅自改分析核心。

## 5. 冻结、重跑和结果格式

1. 先以开发集确定工具Schema、提示、预算、资格与隐私投影；提交固定版本。保留已有失败记录，不只记录成功Trace。
2. 冻结独立oracle与留出场景/维度置换；C_agent输入不得含oracle标签、期待工具序列或最优条件答案。定向明确问题可同时提供给三组，不作为发现的秘密先验。
3. 离线先跑所有Fake/Mock控制、安全、引用、边界和停止测试。Fake可根据上一轮真实工具结果选不同后续动作，但必须标 `scripted_fake`，不代表Qwen智能性。
4. Live另行预先声明 case_ids、每个场景固定重复次数、总调用/Token上限、模型/提示/引擎版本，再申请该轮费用授权。样本不足就如实说有限样例；不得使用最好一轮代替所有轮，也不把模型随机性包装成可重复确定结果。
5. 留出结果不用于本轮调提示后仍自称留出。若改提示/工具Schema，升版本、保留旧结果，安排新的未看场景。
6. 每次保存聚合artifact：case/version/seed/fingerprint、A_default/B_full/C_agent配置、允许目标数、计算/展示签名、拒绝/重复/停止记录、脱敏Trace、实际usage/时延及real/mock/replay来源。录制重放只验协议/引用，不算本次真实调用或新模型质量测试。
7. 宣称增量前，要求三组全部结果相同资格且无安全回归，再看配对场景的新增命中、丢失命中、计算/Token/延迟变化。不规定人为“达标提升率”；不能用只选有利场景凑平均。若只有更多成本或无新增命中，结论写“未证明优于固定流程”。若覆盖提高但耗时/费用更大，分别报告取舍。
