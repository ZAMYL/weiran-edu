# 未然 EDU

面向教师的测评分析前端：学情洞察、画像探索与测评数据管理。依据本地选定的设计稿实现浅蓝顶部导航布局，设计参考资料不纳入代码仓库。

技术栈：Next.js 16 App Router、React 19、TypeScript 5.9、Ant Design 6、ECharts 6、Zustand 5、read-excel-file 9。沿用正式仓库的框架、严格类型检查及 CI；没有引入 Vite 或 React Router。完整技术决策、组件规范、数据规则见 [前端架构说明](docs/frontend-architecture.md)。实际依赖版本由本目录 `pnpm-lock.yaml` 锁定。

## 本地运行

需要 Node 24 与 pnpm 11.25.0，在 `apps/web` 目录运行。

```bash
pnpm install --frozen-lockfile
pnpm dev
```

打开命令输出的本地地址，默认 `http://127.0.0.1:3000/`，首页跳转到 `/insights`。

```bash
pnpm lint
pnpm typecheck
pnpm test:unit
pnpm build
pnpm test
pnpm start
```

生产构建位于 `.next/`，使用 Next.js 原生文件路由。`pnpm test` 包含领域测试和现有的生产服务 smoke 检查，生产检查需要先 `pnpm build`。前端通过路由组 layout 保持批次、筛选条件和全屏上下文。

## 正式数据与 Demo

默认进入正式数据模式，需要连接管理员 CLI 签发的教师临时凭证。三页保留原布局，数据来自 FastAPI：原始双 Sheet Excel 上传、预览与质量报告、版本确认入库、授权批次、五维统计、稀疏矩阵、精确小数 AND 筛选、分页匿名学生、系统评分洞察与指标证据。教师凭证只在内存使用，刷新、结束会话、切换模式或收到 401 后清除。

Next.js 用同源 `/api/edu` 转发到服务端环境变量 `EDU_API_ORIGIN`，默认 `http://127.0.0.1:8000`。不要使用 `NEXT_PUBLIC_*` 配置凭证。启动、认证、测试与阶段边界见 [真实 API 联调说明](docs/api-integration.md)。

洞察和探索页支持保存当前分析，在已保存分析中核验候选为待定、确认或否决，然后预检并导出 XLSX / Markdown 汇总报告。上传 XLSX 自动以文件名命名，预览可改名。具体流程和版本、权限处理见 [教师第五步](docs/teacher-analysis-workflow.md)。

顶部显式切换到 Demo 才启用以下本地演示；演示数据不填补正式模式的空值、空结果或接口错误。

## Demo 已有流程

- 学情洞察：能力雷达与评分分布、重点群体、评语主题检索、证据抽屉与原始记录。
- 画像探索：最多两个条件按“且”组合、草稿与已应用条件区分、热力矩阵单元格筛选、群体分布、分页与学生详情前后切换。
- 测评数据：真实 xlsx 本地解析、问题预览和来源定位、校验阻断、SHA-256 重复文件识别、确认创建独立批次、批次切换与质量报告。
- 三页全屏及 Esc 退出；桌面与窄屏布局；懒加载状态、空结果、文件错误及页面异常提示。

## 运行边界

Demo 的教学分析标注为“规则模板 · 未接入 AI”。Demo 新增批次只在当前页面会话的内存中保留，刷新恢复初始演示批次。正式模式的已确认批次由后端数据库持久化，重新连接授权教师后读取。两种模式都不调用付费模型；正式模式不展示未审核的原始评语或评分依据正文。

演示的 105 名学生与 525 条评分是合成记录，默认群体恰为 21 人 / 20%。均值和图形全部从记录计算，可能与 AI 设计图片的示意数字不同。演示批次中显示的文件与行号是模拟引用，没有读取用户的真实评价文件。

## 导入格式

正式模式只接受当前后端支持的原始双 Sheet 五维 `.xlsx`，评分 1–5、最多两位小数，错误阻断、警告须显式确认当前预览版本。三维、八维及十三题格式尚未实现。

Demo 支持长表格式，第一行为以下四个列名（可调整列顺序）：

| 学生标识 | 能力维度       | 原始评分 | 原始评语         |
| -------- | -------------- | -------- | ---------------- |
| 学生A    | 算法与数据结构 | 2        | 保留实际原始评语 |

每位学生五行，能力维度名称分别为：算法与数据结构、代码实现能力、问题建模能力、效率意识、解题策略。支持多个合规工作表；评分使用 Excel 数值单元格，不能是文本数字。导入后学生显示为批次内的匿名编号，原始标识仍保留在内存模型中。

目前仅提供明确标注的演示 1–5 整数标准。真实测评需要补充实际标准及文件格式适配，不能将演示标准当成正式契约。

- 长表模板：两名示例学生，10 条有效记录。请替换样例内容。
- 待校验示例：一条评分为 6、一条评分缺失；用于验证阻断和定位。

模板由 `node scripts/generate-import-samples.mjs` 可重复生成，并由领域测试解析验证。开发、构建和测试命令会自动生成 `public/templates`，可在测评数据页下载。只提交合成内容的生成源码，不提交 Excel 二进制或真实测评数据。

## 浏览器验证

先启动开发服务，再运行：

```bash
pnpm test:browser
```

Windows 自动使用本机 Chrome；其他环境可先运行 `pnpm exec playwright install chromium`。测试默认访问 3000 端口，可通过 `APP_URL` 环境变量调整。截图和结果输出至忽略跟踪的 `artifacts/` 目录。该项用于本地交互验证，没有修改共享 CI 来安装浏览器。

Demo 测试覆盖页面渲染、证据与分析面板、学生切换、空筛选、有效和无效 Excel、同内容重命名重复识别、全屏状态及 390px 三页布局。真实 API 浏览器验证另运行 `node tests/live-api-smoke.mjs`，会自行启动临时后端与前端；需要先完成生产构建和锁定的 Python 环境安装。截图、运行时 OpenAPI 与结果均留在本地 `artifacts/live-api/`，不提交测试 Excel、数据库或凭证。
