# 教师分析保存、核验与报告导出

沿用蓝白品牌、真实 API、内存教师会话及本机自动测试会话。基于已合并的 #35、#36、#39 接入教师第五步；前端没有修改后端计算、认证、数据库、公共依赖或 CI。

最终产品与复现实测以 [教师工作台说明](teacher-workbench-v1.md) 为准。

## 界面口径

三个模块为「学情诊断」「画像探索」「分析报告」，上传和历史是顶部入口。统一使用「参评人数」「本次测评概况」「测评平均分」「群体差异」；不假设参评者属于同一班级，也不把数据统一归为课堂成绩或固定比赛类型。测评平均分仍是当前各维度有效评分的均值，不生成总分或新的统计口径。

测评名称直接来自已选文件和教师命名；详情仅在已有 course、assessment_date 元数据非空时展示对应信息，缺少名称时使用「测评」，不根据评分维度猜测场景。数据页的课程、日期收进「补充信息（可选）」，没有新增场景必填项。仍先选 Excel、可改默认名称，再点击下一步自动检查并确认导入。

## 使用流程

1. 顶部上传新测评：选择 XLSX，名称自动取文件名且可改，下一步调用实际解析检查，必要确认后自动进入诊断。
2. 代表性发现最多三种，不宣称全量排序；全部发现按类型折叠。评分详情通过方面及具体评分下拉查看，所有指标继续来自真实 API。
3. 在诊断或探索选择发现后进入分析报告；待保存选择在内存中跨页面保留，批次、条件、快照或教师变更时清除。
4. 独立报告页复用原保存和核验实现。未选发现仅保存概况，不自动加入未确认结论。已有旧版统计分析仍可从保存列表核验和导出。
5. 三态为待教师确认、已确认、不采纳；保存版本、预检、权限、快照和文件校验保持原行为。

## 权限、版本与错误

- 批次所有者可保存、编辑。获授权只读教师可查看列表、读取结果及导出，不能编辑判断。界面读取 capabilities，后端仍逐请求核验。
- 保存、读取、核验、预检、下载始终绑定同一批次和 snapshot_id。保存结果使用自己的查询上下文，不跟随工作台后来修改的筛选。
- 核验冲突保留本地修改并显示真实 409 错误；须显式加载最新版，不自动覆盖他人核验。预检不锁版本或权限，实际下载再次由后端核验。
- 预检或下载失败时显示安全提示、真实状态码对应的错误码及服务端请求编号；不创建文件。版本冲突后可关闭并加载最新结果，快照冲突走既有「刷新批次」入口。
- 401 沿用现有会话清理，批次/模式/会话变化取消未完成请求和下载。没有新登录页、凭证持久化或发布权限。

## 下载验证

同源代理仅增加所需的 capabilities、analysis-results、export-check 与 XLSX/MD 下载白名单。报告必须显式携带 format、snapshot_id 和正整数 expected_version。

代理和浏览器均验证 200 状态、对应 MIME、与结果 ID/版本/格式一致的安全附件名、完整长度和 8 MiB 上限。XLSX 检查 ZIP 文件签名，Markdown 检查 UTF-8 与报告标题；JSON/HTML、异常附件名、截断响应不能当文件保存。服务端失败 JSON 保留原状态和请求编号，不带附件头。下载后清理临时链接与 Blob URL。

## 本地验证

先按 [API 联调](api-integration.md) 准备锁定 Python 环境和生产构建：

```bash
pnpm lint
pnpm format:check
pnpm typecheck
pnpm build
pnpm test
node tests/live-api-smoke.mjs
# 自动测试会话路径：设置 EDU_BROWSER_TEST_SESSION=1 后再运行同一脚本
```

live-api-smoke 在仓库外临时 SQLite 和合成教师中调用真实 FastAPI 与生产 Next.js。teacher-analysis-flow 覆盖保存原查询、三态核验持久化、评分证据、两种报告、预检提醒确认、核验和下载版本冲突、预检后撤权、只读教师、服务端分页及手机核验页面。原有上传、统计、权限失效与 Demo 隔离回归继续运行。

单元测试覆盖错配快照/候选、请求字段、附件验证、长度预算、失败 JSON、会话变更取消及 Blob 清理。截图、运行时 OpenAPI 和结果只保留在被忽略的 artifacts 目录；不提交真实表格、数据库、凭证或设计图。

PR 交组长产品验收，不自动合并。尚未增加评语审核写入口、JSON/ZIP/PDF 导出、多格式导入或新的分析算法。
