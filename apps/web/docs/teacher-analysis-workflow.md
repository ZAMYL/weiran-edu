# 教师分析保存、核验与报告导出

沿用现有三页布局、真实 API、内存教师会话及本机自动测试会话。基于已合并的 #35、#36、#39 接入教师第五步；前端没有修改后端计算、认证、数据库、公共依赖或 CI。

## 界面口径

三个模块保留「学情洞察」「画像探索」「测评数据」。统一使用「参评人数」「本次测评概况」「测评平均分」「群体差异」；不假设参评者属于同一班级，也不把数据统一归为课堂成绩或固定比赛类型。测评平均分仍是当前各维度有效评分的均值，不生成总分或新的统计口径。

测评名称直接来自已选文件和教师命名；详情仅在已有 course、assessment_date 元数据非空时展示对应信息，缺少名称时使用「测评」，不根据评分维度猜测场景。数据页的课程、日期收进「补充信息（可选）」，没有新增场景必填项。仍先选 Excel、可改默认名称，再点击下一步自动检查并确认导入。

## 使用流程

1. 正式测评上传无需提前命名。选择 XLSX 后停留在上传步骤，默认用不含扩展名的文件名作为测评名称，可直接修改、重新选择或取消。点击「下一步：预览校验」才上传和校验，进入预览；预览中仍可修改，改名后的警告确认绑定新的预览版本。Demo 同样由教师点击下一步推进。
2. 在学情洞察或画像探索点击「保存本次分析」。保存当前批次、快照、已应用的 AND 筛选及是否包含维度候选。探索页有未应用的筛选草稿时，先应用筛选再保存。
3. 名称和备注可修改。服务端重新计算并保存完整统计、群体和候选；当前分页不会截断保存内容。前端不提交统计、匿名学生或自行拼造的候选。
4. 保存后进入核验抽屉，也可从「已保存分析」分页重新打开。系统候选与教师待定、确认、否决分别展示；候选的评分证据使用保存时的查询条件回查。
5. 修改判断或备注后点击「保存核验结果」。保存携带 expected_version；有未保存修改时暂停导出。返回列表、关闭或加载最新版前会提示放弃未保存修改。
6. 点击「导出测评报告」，选择 XLSX 或 Markdown。每次打开及切换格式重新读取当前能力并进行对应格式的预检。有提醒时须显式确认；切换格式清除上一次确认。

报告只含汇总统计与教师已确认发现；不含匿名逐人明细、教师自由备注或原始评语。预检展示的群体人数是分析匹配人数，不是报告个人明细行数。预估大小使用 report_payload_bytes，不使用 JSON 载荷大小。

## 权限、版本与错误

- 批次所有者可保存、编辑。获授权只读教师可查看列表、读取结果及导出，不能编辑判断。界面读取 capabilities，后端仍逐请求核验。
- 保存、读取、核验、预检、下载始终绑定同一批次和 snapshot_id。保存结果使用自己的查询上下文，不跟随工作台后来修改的筛选。
- 核验冲突保留本地修改并显示真实 409 错误；须显式加载最新版，不自动覆盖他人核验。预检不锁版本或权限，实际下载再次由后端核验。
- 预检或下载失败时显示安全提示、真实状态码对应的错误码及服务端请求编号；不创建文件。版本冲突后可关闭并加载最新结果，快照冲突走既有「刷新批次」入口。
- 401 沿用现有会话清理，批次/模式/会话变化取消未完成请求和下载。没有新登录页、凭证持久化或发布权限。

## 下载验证

同源代理仅增加所需的 capabilities、analysis-results、export-check 与 XLSX/MD 下载白名单。报告必须显式携带 format、snapshot_id 和正整数 expected_version。

代理和浏览器均验证 200 状态、对应 MIME、与结果 ID/版本/格式一致的安全附件名、完整长度和 8 MiB 上限。XLSX 检查 ZIP 文件签名，Markdown 检查 UTF-8 与报告标题；JSON/HTML、异常附件名、截断响应不能当文件保存。服务端失败 JSON 保留原状态和请求编号，不带附件头。下载后清理临时链接与 Blob URL。

## 本地验证

先按 [API 联调](api-integration.md) 准备锁定 Python 环境和生产构建：

```bash
pnpm lint
pnpm format:check
pnpm typecheck
pnpm build
pnpm test
node tests/live-api-smoke.mjs
# 自动测试会话路径：设置 EDU_BROWSER_TEST_SESSION=1 后再运行同一脚本
```

live-api-smoke 在仓库外临时 SQLite 和合成教师中调用真实 FastAPI 与生产 Next.js。teacher-analysis-flow 覆盖保存原查询、三态核验持久化、评分证据、两种报告、预检提醒确认、核验和下载版本冲突、预检后撤权、只读教师、服务端分页及手机核验抽屉。原有上传、统计、权限失效与 Demo 隔离回归继续运行。

单元测试覆盖错配快照/候选、请求字段、附件验证、长度预算、失败 JSON、会话变更取消及 Blob 清理。截图、运行时 OpenAPI 和结果只保留在被忽略的 artifacts 目录；不提交真实表格、数据库、凭证或设计图。

PR 交组长产品验收，不自动合并。尚未增加评语审核写入口、JSON/ZIP/PDF 导出、多格式导入或新的分析算法。
