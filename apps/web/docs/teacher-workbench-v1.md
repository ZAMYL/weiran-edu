# 教师工作台：最终产品口径与验收

本轮继续使用 `feat/teacher-analysis-review-export` / PR #40。固定集成基线为 #63 的 `d7d902cd939d390cec3a5e4fd960cf62911afbc2`，没有修改 #63 分支、后端算法、公共接口、数据库、依赖或 CI。

产品定位：**未然 EDU｜AI 时代的编程能力与学习成效诊断平台。**

## 2026-10-28 四项优化

- 上传选择、名称和已建立的预览随教师会话在内存保留，切换页面后回到上传可继续；结束或更换会话清除。名称为空时允许使用后端文件名默认值。已有测评优先使用其仍有导入权限的数据来源，多来源且无上下文时要求明确选择，不擅自取第一个。
- 预览显示后端 `recognized_items`、完整文件记录数及真实量表，记录数不冒充去重人数。确认保留返回的 `batch_id/snapshot_id`；随后批次读取失败时只重试读取，校验同一快照，不重传文件或再次创建批次。旧后端缺少新增字段时不补造识别结果。
- 右侧重点发现逐项下拉切换，一次展示一张，保留最多三项不同类型的代表性发现及跨切换选择。已选发现可直接前往报告；完整结果继续在下方按类型展开，不更改后端排序、人数或资格。
- 统一评分、人数、比例、评分选项、图表提示、解释与报告范围数字；评分和比例最多两位小数，去掉多余零和负零。显式 Fraction 只作显示转换，人数分母及原始证据值保留。
- 报告页可逐项移除待保存发现。保存成功直接显示核验结果，不再混放待保存区域；已保存结果的引用在内存中保留，返回页面重新请求后端。新选发现优先进入新草稿。核验进度、未保存修改、保存与导出集中呈现，版本及预检校验沿用现有接口。

文件和未确认预览仅保存在当前教师会话内存；浏览器完整刷新或结束会话后不承诺恢复本地文件。已经正式导入的测评仍从后端恢复。没有把文件、分数、权限或报告正文写入浏览器持久缓存。

## 教师路径

- 一级导航只有学情诊断、画像探索、分析报告。当前测评选择、上传新测评、查看历史测评放在顶部工作台；`/data` 只保留兼容入口。
- 无授权测评时，诊断首页直接展示上传。选择文件后以文件名填入测评名称，可改名；点击下一步调用真实解析检查，必要确认后导入并自动进入该测评诊断。
- 再次上传自动切换到新批次。浏览器仅保存按教师隔离的最近批次标识，重新连接时逐次请求后端核验；授权失效则回退至实际可读批次。没有持久化教师凭据、统计或学生数据。禁用浏览器存储时仍可从后端列表选择测评。
- 问题按后端类型汇总真实影响人数与条数，提示核查建议。原始记录、完整问题分页、位置定位及技术信息可以展开，警告确认仍绑定实际预览版本。前端不清洗、改分、选择解析器或伪造格式支持。
- 测评概况压缩到页面右上角，全屏入口放在顶部导航。下方桌面主卡片等宽等高，并列呈现评分画像和学情分析：右栏默认重点关注，可像左栏一样用分段按钮切换评分统计；上方不再单独占整行。切换保留发现选择与统计状态，完整发现仍在下方按需展开。代表性发现最多三类，只选当前返回页，明确不代表全量价值排序。完整发现按类型展开为紧凑行列表。
- 涉及人数读取受控详情，不从摘要猜测；详情读取数量有限且顺序执行，用户打开详情时取消背景读取，避免压满发现计算预算。
- 发现的进一步探索保留批次、快照、外层条件、发现 ID 和后端声明的成员指标。复杂原群体通过受控记录接口重放，不简化为近似条件。教师主动应用新条件后，分布、人数和成员均使用真实匹配结果；全体评分组合仅作为明确标注的重选参考。
- 待保存发现只在内存中跨路由保存，最多三项；换批次、快照、条件或教师会话后清除。加入待保存、已保存版本、待教师确认、已确认、不采纳分别显示。
- 报告复用原保存、三态核验及导出实现。未选择发现时只保存真实范围概况，不自动补入结论。XLSX/Markdown 仍逐次检查权限、快照、结果版本、预检和警告；失败 JSON、错误 MIME、附件签名或尺寸异常均不能下载。

## 真实能力与限制

- 正式解析仍受实际后端支持的 XLSX 结构限制，当前是双工作表五维格式；教师不需要预选模板或映射。不承诺通用 Excel、任意维度或自动清洗。
- 正式发现来自可信计算。没有调用 Qwen、开发 Agent、模拟工具轨迹、假 AI 状态或假调查按钮。
- 原固定演示仅供内部回归：本机开发环境或显式 `EDU_ENABLE_DEMO=1` 时访问 `/dev/demo`。正式工作台没有模式开关，内部样例始终有明显合成数据提示，不参与真实分析。非开发生产环境默认拒绝该入口。
- 凭据仍采用既有内存会话；未配置本机测试会话时，刷新后可能需要重新连接账户，已导入测评仍在后端，不需要重传。
- **正式发现保存和导出依赖后端 #61，新增上传识别及快照交接依赖上传分支。** 本轮已抓取远端，固定组合报告后端 `27212f60216ff97d7e98ef27111edb7eacf8346c` 和上传分支 `24c442cf9b48e11886fdaf45ac9e644b23e7c2d6` 相对 `5218af4daa621f6a39ed1055481790d708e7459f` 的 `apps/api` 补丁。组合仅位于忽略的 `.local/qa/backend-final`，没有修改其他分支或把后端代码纳入本次前端提交。不能将隔离联测宣称为 main 已具备这些能力。

## 复现和实际截图

依赖安装、Node/Python 环境与现有仓库一致；在 `apps/web` 执行必需检查：

```powershell
pnpm lint
pnpm format:check
pnpm typecheck
pnpm build
pnpm test
```

以下脚本使用实际 FastAPI、生产 Next 代理、Chromium、临时数据库和合成 XLSX。通过 `EDU_TEST_API_ROOT` 指向上述组合的 `apps/api`，`EDU_TEST_PYTHON` 指向已有锁定 Python 环境；`EDU_TEST_BACKEND_REVISION` 可记录上述两个固定版本：

```powershell
node tests/teacher-layout-e2e.mjs
node tests/teacher-product-e2e.mjs
node tests/credential-relay-e2e.mjs
$env:EDU_BROWSER_TEST_SESSION='1'
node tests/live-api-smoke.mjs
```

`teacher-layout-e2e` 实际上传 105 人与 17 人合成表格，验证首次导入、自动切换、零发现、原群体与证据、报告待保存状态、选择较早测评后刷新与重开，以及历史入口。新增切页保留文件和预览、真实识别项目与确认快照、重点发现切换保留选择。另明确注入一次确认成功后的批次 GET 503，断言重试不发送第二次 commit；正常路径仍使用真实 API。

`teacher-product-e2e` 验证 53 人原群体 26/27 精确成员重放、核验持久化、报告页返回续接、新草稿不被旧报告覆盖、单项移除、打开真实 XLSX/Markdown 文件、409 保留修改、只读403、撤权404和失效401。已有旧统计报告和失败附件回归继续由 `live-api-smoke` 执行。

截图均来自实际页面，尺寸为 1920×1080、1440×900、390×844；输出位于被忽略的 `artifacts/discovery-flow/after-*`、`artifacts/teacher-product/`。`layout-checks.json` 记录布局边界，`product-result.json` 记录报告及权限检查。图片、合成导出、数据库、凭据、真实表格和 design 不随代码提交；组长验收时可复跑脚本或使用当前工作区截图。
