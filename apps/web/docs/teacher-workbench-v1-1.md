## 接口与当前范围

前端已按 #71 `82f64651eb8c157ae9a9da1c2664e32321a1c4c2` 的实际契约接入。上传以 `format=edu-question-xlsx.v1` 分流，保留原题名和十进制字符串量表。批次列表显式请求 `include_dynamic=true`，同时支持逐题批次列表与详情的不同响应形状。诊断使用同批次、同快照的 `item_statistics`；画像探索按 `item_id` 筛选。分布比例以服务端全体参评人数为分母。评分依据抽屉显示服务端记录键、质量状态和原文件单元格，来源摘要按需展开。

真实 Next + #71 FastAPI + 临时 SQLite 的 20 人 13 题已通过上传、质量确认、入库、统计、分布、依据、刷新重开与切换测评。260 条观测中 256 有效、1 缺分、1 非法数值、1 超量表、1 步长不合法。逐题发现、报告、答卷复核、任意 Excel 布局和动态题数仍未开放。V1 旧批次继续使用原授权、发现、报告与导出。

## 学情诊断内的 Research Agent

入口显示在现有学情诊断内容上方。教师选定测评后提交问题、当前批次和快照，候选覆盖本次测评全部授权参评者。正在运行、已停止、失败和证据不足只按服务端回执显示。切换批次后，上一批次的任务和结果不在当前批次渲染。

| DTO 核对项     | 前端所需语义                                                                                                           |
| -------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 问题与范围     | 问题文本和服务端限长，批次、快照、原分析条件，服务端检查权限与能力。                                                   |
| 任务状态和停止 | 任务引用、读取方式、实际运行与终止状态。用户发出停止请求后，等服务端确认终止。区分取消、证据不足、覆盖不足和预算耗尽。 |
| 发现和证据     | 后端返回现有正式发现引用，或提供经过服务端核验的映射。引用需带原发现 ID、原范围参数、输入引用及可用的证据指标键。      |
| 错误           | 保留 HTTP 状态、结构化错误和请求编号。没有完成或证据不足时说明当前结果和限制。                                         |
| 分析来源       | 确定性分析沿用当前发现入口。离线 Mock 仅在隔离验收中标记。获批的真实模型执行由服务端返回来源和能力状态。               |

第二阶段已接入 `0c73569` 候选的单一合成任务契约。卡片通过原证据抽屉和探索条件回查，待核查结果经服务端正式重算后进入原报告核验与导出。入口只在显式开启的本机合成宿主显示。部署教师入口和动态逐题 AI 仍关闭，详见[实际接线与限制](ai-synthetic-frontend.md)。
