- 保持蓝白品牌和三项主导航：**学情诊断、画像探索、分析报告**。取消四步一级导航；测评数据不是一级模块。
- 产品介绍：**未然 EDU｜AI 时代的编程能力与学习成效诊断平台。**
- 顶部左区是标题、测评选择、上传新测评和历史入口；右区是当前测评概况，与下面两张等宽等高卡片对齐。全屏按钮在导航栏。窄屏两区按顺序上下排列。
- 下方左卡是评分画像，右卡是学情分析；右卡保留「重点关注 / 评分统计」切换。不要恢复为上方整行发现卡、右侧无限长列表或嵌套滚动。
- 使用测评、参评人数、群体差异等口径，不默认同班，不硬编码算法比赛或课堂成绩。只有明确元数据才显示课程等场景。
- 选择文件后默认填入文件名，教师可改名；保留显式“下一步：预览校验”，不在选文件瞬间跳走让改名失效。检查之后只保留必要确认，成功自动打开实际返回批次。
- 正式结果全部来自后端。原固定演示保留为内部 `/dev/demo`，明确合成样例，不能混入正式模式。
- 沿用内存教师会话和本机自动测试会话，不重做登录，不把正式发现标成真实 Qwen 自主生成，不开发 Agent。

## 4. 本轮前端已完成

### 上传连续性

- 文件、可编辑名称、可选元数据和预览引用保存在当前教师会话内存。切到其他页面、再从上传入口回来可继续，历史列表不会被旧预览挡住。
- 名称清空后仍可进入检查，由后端使用安全文件名默认值；不强制预先命名。已有测评优先选用其仍可导入的数据来源；多个来源且没有上下文时要求明确选择。
- 解析中的步骤显示“自动检查”，获得真实预览后进入“确认导入”。没有伪造进度百分比、解析任务或格式支持。
- 接入 `recognized_items`，显示后端实际识别的项目和评分量表。文件参评记录数不冒充去重人数；有效、缺失、无效评分沿用完整质量报告。
- 问题按类型聚合，完整列表、分页、原始定位仍可展开；改名后清除旧警告确认，继续绑定实际预览版本。
- commit 成功保留 `batch_id/snapshot_id`，随后的批次读取失败可“重新打开诊断”；重试只读同一批次，不重复上传或再次 commit。核对返回快照，不用文件哈希或前端 UUID 替代。
- 会话失效或切换会清除上传草稿。文件不写入浏览器持久存储；完整刷新后未提交文件不保证恢复，已正式导入的测评从后端恢复。

### 发现布局

- 当前返回页最多选取三种不同类型的代表发现，用下拉逐项查看，一次只显示一张重点卡。
- 在不同发现及“重点关注 / 评分统计”之间切换会保留加入报告的选择；已选时可直接前往报告，也可清空。
- 涉及人数、原群体及证据仍来自受控详情；保留原条件、批次、快照、发现 ID，不把复杂群体简化成不等价条件。
- 全部发现继续按类型展开、分页读取。明确仅针对当前返回页，不能声称已做全量价值排序。

### 数字显示

- 人数按整数显示；评分和比例最多两位小数，去掉无意义尾零、负零。
- 评分统计、评分下拉、图表提示、发现说明、探索比例和报告范围使用统一显示函数。
- 对可识别的 Fraction 与评分分数表达只作展示转换，不改变 API 原值、统计计算、人数分母或证据。
- 原始证据数值保留用于回查；不要为显示整洁而改写请求中的精确阈值或舍入后再查询。

### 报告操作

- 报告页支持逐项移除待保存发现。保存后直接进入核验结果，不再同时残留“待保存内容”大块区域。
- 当前已保存报告只在内存保留引用，离开后返回重新从后端读取；新选择的发现优先进入新草稿，不被旧报告引用覆盖。
- 明确显示待教师确认、已确认、不采纳的数量及未保存状态。保存与导出集中在底部操作区；有修改时先保存再导出。
- 继续复用原保存、三态核验、权限/快照/版本保护、XLSX/Markdown 预检和文件校验。失败 JSON 不会下载成文件；教师未确认发现不变成已证实结论。
